# Omarchy

- `omarchy update` legt selbst einen Snapper-Snapshot an; Beschreibung ist die alte Version (z. B. `4.0.6-1`).
- `omarchy-version` statt `omarchy --version`.
- Das aktuelle Theme steht in `~/.local/state/omarchy/current/theme.name`.
