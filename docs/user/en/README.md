# Seldon user guide

Seldon records every change to your Omarchy system, matches it against
what you planned, and shows the difference. This guide shows you how to
install it, how it thinks, and how to use it every day, alone or with
your AI agents.

New here? Start with [Getting started](01-getting-started.md). It takes
about fifteen minutes.
