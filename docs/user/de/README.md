# Seldon-Anleitung

<!-- source: en/README.md @ 2e4bfa8 -->

Seldon zeichnet jede Änderung an deinem Omarchy-System auf, gleicht sie
mit dem ab, was du geplant hast, und zeigt den Unterschied. Diese
Anleitung zeigt dir, wie du es installierst, wie es denkt und wie du es
jeden Tag benutzt, allein oder mit deinen KI-Agenten.

Neu hier? Fang mit [Erste Schritte](01-getting-started.md) an. Das dauert
etwa fünfzehn Minuten.
