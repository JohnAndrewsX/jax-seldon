# WP-117 — Plugin texts and the privileged-step terminal (UX review, 0.1.4)

Role: Plugin Dev (Opus, high). Ships in 0.1.4. Text-level; no contract
change; no new engine call.

## Goal

The panel's setup moments feel like Omarchy: one sentence per banner,
one action, and every terminal the panel opens says what it will do,
shows the command, and says what changed (operator, 2026-10-06: "the
terminal should explain what is about to happen and show the command").

## Inputs

The UX review (private field notes of the first productive setup; the
orchestrator hands the relevant sections over: §1c, §2, §5 and the
0.1.4 list items 3–4) — summarised here:
- Snapshot read grant: *Run in terminal* runs a fixed `SNAPPER_FIX_SCRIPT`:
  a `gum style` announce (what, why, "asks for your password once"), the
  command echoed, the command, then `seldon capture` and a result line
  (success: "Snapshots are now recorded. The panel updates by itself.";
  failure: "Nothing changed. Snapshots stay off; Seldon works without
  them."). Copy still copies the plain command. Remove `SNAPPER_HINT`
  ("press Check again") and its plumbing.
- The same announce/command/result pattern for the other terminals the
  panel opens (engine install, `seldon init`).
- Banners: one sentence each; buttons *Install*, *Create*, *Grant*; the
  engine-missing banner in the accent tone (not urgent) when no index
  exists; "1 events today" → "1 event today" (plural).
- Every script is a fixed string with nothing from the index in it
  (AGENTS.md §8); `gum` is part of every Omarchy 4 host.
plugin/Model.js (fix commands ≈ 52–77, Today stats ≈ 1057),
plugin/Service.qml `fix()` (≈ 667), plugin/components banners,
docs/SPEC-PLUGIN.md §5, plugin README; Omarchy's own scripts
(`$OMARCHY_PATH/bin`, those using `gum`) and
`omarchy-launch-floating-terminal-with-presentation` as the model.

## Acceptance

Harness cases for each banner text and button, the fixed script strings
(contain the command verbatim, nothing from the index), the plural;
`omarchy plugin validate plugin/`, `qmllint`, `just check` 0. The
orchestrator runs the snapshot grant live on the fresh test host.
Review: stage 1 Opus, stage 2 Fable (unsandboxed plugin, shell strings).
