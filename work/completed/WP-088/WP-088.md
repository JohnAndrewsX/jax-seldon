# WP-088 — State-reset follow-ups: pending baseline and own-change catch-up

Role: Engine Dev (Opus, high). 0.1.4 wave 1. Files: engine/src/commands/
capture.rs, engine/src/reconcile.rs, engine/src/collectors/mod.rs
(`CollectorState` only). **Not** doctor.rs, not sys.rs, not the six
collector modules. Follow-ups from the WP-083 and WP-086 reviews.

## Goal

(a) A collector that is degraded in the capture that records a state
reset keeps a "pending baseline" mark, so its first later successful run
records its gap (as the others did in the reset capture) instead of
looking like "never ran here".
(b) Own changes that rule 8 would explain but that are still unresolved
(a crash between the appends, rows from before 0.1.3) are explained by a
catch-up pass on the next capture.

## Inputs

engine/src/commands/capture.rs (`pending_reset`, rule 8 near line 171),
engine/src/reconcile.rs (`explain_own_changes`), engine/src/collectors/
mod.rs (`CollectorState`, `cursor_reads`), engine/src/attribution.rs
(`own_change`, `OWN_PLUGIN`), docs/SPEC-ENGINE.md §5 (rule 8, state
reset), work/completed/WP-081, WP-083, WP-086 handovers.

## Outputs

- (a) A boolean on `CollectorState` (`#[serde(default)]`, skipped when
  false). The typed cursor value is unchanged; existing cursors.json files
  read unchanged; `cursor_reads` and the collectors are untouched;
  `pending_reset`'s signature stays as it is (doctor shares it). Cleared
  on the run that records the gap. Tests: degraded-in-reset → later
  success records the gap once; idempotent on a second capture; an old
  cursors.json without the field loads.
  Amended after review: the mark records the lost kind (cursors | logbook) instead of a boolean.
- (b) Catch-up explains only the kinds rule 8 explains today (plugin
  update/enable/disable of `jax.seldon`, package upgrade/reinstall) and
  only rows without a resolution; a dismissed or otherwise resolved row
  keeps its resolution; no case is created. Tests incl. a dismissed row
  and an add/downgrade row that stays drift.
- Two commits, mutants per part. SPEC §5: replace the rule-8 "resolve it
  by hand" sentence; state-reset paragraph; CHANGELOG lines.

## Acceptance

`just check` 0; mutants listed per part. Review: stage 1 Opus, stage 2
Fable (engine core).
