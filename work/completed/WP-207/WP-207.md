# WP-207 — the budget test holds on every host

0.2.x, tests only. From CI run 38185406818 on `next` 1e872c28
(2026-10-12): `engine/tests/index.rs`
`status_writes_a_large_logbook_under_its_budget` (WP-200) expects the
warning to end in "… completed cases, 216 events; …"; on CI the engine
cut 215 events ("written at 999979 bytes without 40 completed cases, 215
events"). The orchestrator's gates on the dev host passed. The number of
rows the cut takes depends on the bytes the index holds, and some of
them vary between hosts (the temporary logbook path, the home path, or
another host-dependent string in the index).

Role: Engine Dev (Opus, high). Reviewer: Opus.

**Do.** Find which part of the index varies by host and say it in the
handover. Make the test hold on every host without weakening what it
proves: it still checks that the written index is under the budget, that
the warning names the largest section and what was cut, that only
history goes (completed cases and events) and that every count, crisis
row and open case stays. Compute the expected cut from the build rather
than a constant, or pin the host-dependent strings in the test; do not
loosen the warning to a prefix only. Check the other WP-200 tests for the
same dependency. No engine change unless the varying bytes are a defect.

**Acceptance.** The test passes with a temporary path 60 characters
longer and 30 characters shorter than the dev host's (say how); CI green
on the branch's merge into `next`; `just check` green; evidence words in
the handover.

**Inputs.** `engine/tests/index.rs` (the WP-200 tests),
`engine/tests/common/`, `engine/src/index/budget.rs`,
`engine/src/index/build.rs`; ADR-0053; CI run 38185406818.
