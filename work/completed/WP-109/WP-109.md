# WP-109 — Engine: drift classification by consequence (ADR-0028 WP-A)

Role: Engine Dev (Opus, high). Ships in 0.1.4. No contract change (the
schema *description* of `crisis` changes; `contractVersion` stays 1).

## Goal

Every drift-eligible event gets a class — routine, attention or crisis —
computed at index time from the ledger and `[drift]` config, by the total
table of ADR-0028 §2. Routine events leave `index.drift`; `crisis` is the
harm test, no longer "zone is red". Nothing is written to the ledger.

## Inputs

decisions/ADR-0028-attention-by-consequence.md (normative: §2 table, §3
agent refusal, §4c/§4d config and watch paths incl. the operator's
decision on existing default lists, §5 migration, §7 contract, §8 WP-A),
ADR-0008/0012/0013/0014/0020/0021, docs/SPEC-ENGINE.md §2, §4, §5, §6,
engine/src/index/{drift.rs,build.rs}, engine/src/reconcile.rs,
engine/src/config.rs (`alwaysRed`, default `watchPaths`),
engine/src/collectors/{config.rs,omarchy.rs,pacman.rs},
scripts/validate-fixtures.py, fixtures/index.sample.json, schema/.

## Outputs

As ADR-0028 §8 WP-A: class after rules 1–3 with group = max of members;
`[drift] attention, routine, routinePaths, routinePackages,
alwaysRedPaths` with the §2 defaults; `crisis` by harm test;
`drift[].zone` stays the ledger zone; `drift --all`, `drift show` with
`class` and `rule` (from folded events, not the capped `index.drift`); a
linkable set separate from open drift (`drift link` of a routine event
resolves it; `explain|dismiss` of a routine event exits 1 "routine");
the engine refuses an agent actor's `explain`/`dismiss` of a crisis and
allows `link` only to the agent's own case; capture marks
`meta.matches = omarchy-default | system-link`; built-in template hashes
as rule-7 evidence; the six new default `watchPaths` (§4d: new config
gets them; an existing config whose list equals an earlier default gains
them once with one capture line; a user-changed list keeps its own and
`doctor` names the missing paths); `doctor` prints the effective
`[drift]` set and marks non-defaults; `series.drift` never negative;
the rules ported to `scripts/validate-fixtures.py`; the fixture rows of
§8; SPEC-ENGINE §2/§4/§5/§6; schema description of `crisis`; CHANGELOG.

## Acceptance

Table-driven test over every §2 row incl. `-Syyuu`, `:: Replace`,
`config-remove` and Omarchy's update line as it stands in
`$OMARCHY_PATH/bin/omarchy-update-system-pkgs`; two index builds
byte-identical; zero ledger writes (mutant: a build that appends fails);
migration fixture with open theme/toggle/update/`-Syu` drift → `drift`
empty, ledger byte-identical, old resolutions still fold, series never
negative; `attention = "all"` reproduces the pre-ADR golden index; the
watch-list upgrade (default list → gains paths once; changed list →
untouched, doctor row); `just check` and `just check-perf` 0; mutants.
Review: stage 1 Opus, stage 2 Fable (engine core, security classes).

## Omarchy first (operator, 2026-10-06)

Read Omarchy's own agent skill before deciding a path or rule:
`$OMARCHY_PATH/default/agents/skills/omarchy/` (`SKILL.md`, `theming.md`,
`hooks.md`, `plugins.md`, `hyprland.md`) and `omarchy commands --json`.
What it implies for this WP (refine ADR-0028's table only where it is
silent; a change to a row needs the orchestrator):

- `omarchy refresh <app>` backs up with a timestamp and copies the
  default: the `omarchy-default` mark and the `**/*.bak.*` routine path
  must cover exactly that pair (test with the real backup name pattern).
- Themes: `~/.config/omarchy/themes/<slug>/` is an overlay or a user
  theme; files that run code (`*.lua`, the terminal configs, `vscode.json`)
  are attention like `hypr/*.lua`; everything else of a theme (e.g.
  `colors.toml`, `*.theme`, `shell.toml`) and `~/.config/omarchy/backgrounds/**`
  is routine (`theme-assets`). A theme with a `.git` directory was
  installed by `omarchy theme install`, which strips code: its files are
  routine. `~/.config/omarchy/themed/*.tpl` stays attention.
- Hooks: `hooks/<name>.d/*` and the flat `hooks/<name>` both run; both
  are crisis paths; `*.sample` is not.
- `~/.config/omarchy/extensions/omarchy-menu.jsonc` (menu entries run
  commands) is attention.
- `~/.config/omarchy/plugins/<id>/` hot-reloads code on save: tree
  hashing is WP-113; do not widen it here.
