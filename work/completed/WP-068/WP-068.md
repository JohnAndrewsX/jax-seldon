# WP-068 — plugin: engine-call failures logged and retried, busy sheets say so, engine minimum checked

Role: Plugin Dev (Opus, high). Size: M. Wave: 3. Depends: WP-060
(`Model.js`, `Service.qml`, plugin tests). Findings: F-456, F-551, F-553,
F-555, F-457 (Info).

## Goal

- **F-456** — every engine call that exits above 0 logs one
  `console.warn` with the exit code and the first stderr line (Service.qml
  runnerDone ~407-422).
- **F-551** — exit 4 (lock held) of a background `capture`/`status` is
  retried later (30 s, at most 3 times) with a neutral text, not shown as
  an error.
- **F-553** — when a one-at-a-time guard refuses (Service.qml ~255, ~277,
  ~296), the caller gets a result "another action is running — try again
  in a moment" that the New case and Drift sheets show.
- **F-555** — the Drift sheet no longer resets `armedSig`/`notice` on
  every index reload (DriftSheet.qml ~235-238); `notice` clears only on a
  user edit or a `sig` change.
- **F-457** — `probeDone` compares the engine version with `engineMin`
  (manifest.json ~31) and shows an "update the engine to at least X"
  banner variant with the fix action.
