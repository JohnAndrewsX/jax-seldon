# WP-023 — Decisions and Memory tabs

## Goal
The last two panel tabs: decisions (ADR list, "New decision") and memory
(lessons headings, memory topics), both read from the index, both opening
files in the editor.

## Inputs
docs/SPEC-PLUGIN.md §5 (Decisions and Memory rows), §8, §9, docs/CONTRACT.md
(`decide --no-edit -- <title>`, `open ADR-… --editor --json`), docs/SPEC-ENGINE.md
§3 (`decide` JSON shape; `open` targets incl. `ADR-…`), schema/index.schema.json
(`decisions[]`, `memory`), fixtures/index.sample.json (4 decisions, 3 lessons,
2 topics), plugin/ (WP-021 merged: tabs, sheets, arming, Service queue),
tests/plugin/, work/completed/WP-{011,020,021}/HANDOVER.md.

## Outputs
- `plugin/components/DecisionsTab.qml` (digit 4): list newest first (id,
  title, status, date, linked cases), Enter/`e` opens the ADR in the
  editor (`open ADR-NNNN --editor --json`, id validated `^ADR-[0-9]{4}$`);
  *New decision* (sheet: title → `decide --no-edit --json -- <title>`,
  then `open <newId> --editor --json` from the result; two-press arming;
  text kept on refusal).
- `plugin/components/MemoryTab.qml` (digit 6): `memory.lessons` headings
  and the other memory files with `updated`; Enter/`e` opens
  `memory/lessons.md` or the topic file (`open memory --editor`? — if the
  engine's `open` has no memory target, propose the one-line engine
  addition `open memory[/<file>]` under "Decisions needed" and use
  `open logbook` meanwhile).
- `plugin/Model.js` helpers (`decisionRows`, `memoryRows`, `decideArgs`,
  `decideResult`); `validateArgs` for the `decide` and `open ADR-…` forms.
- Tests: node tests; fake-seldon answers `decide` (creates an ADR in its
  index) and `open ADR-…`; service-states exact argv; panel-view scenarios
  (lists on the sample, new decision flow, keys 4/6, open variants).
- README, TESTING, offscreen renders in three themes.

## Acceptance tests
- `just check` exit 0.
- On the sample: 4 decisions (1 proposed first or newest first per spec),
  3 lessons and 2 topics render; Enter opens the right path (fake
  launcher records it).
- "New decision" calls `decide --no-edit --json -- <title>` and then
  `open <id> --editor --json`; a refused title keeps its text.
- Runtime smoke on the test host with the real engine (IPC-driven if the
  session is locked; keys only when unlocked).

## Constraints
As WP-021. Digits 4 and 6 are fixed per SPEC-PLUGIN §5.
