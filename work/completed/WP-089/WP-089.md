# WP-089 — Environment: OMARCHY_PATH default and desktop entries in the watch paths

Role: Engine Dev (Opus, high). 0.1.4 wave 1. Files: engine/src/sys.rs,
engine/src/collectors/{omarchy,plugins,config}.rs, engine/src/dossier/
query.rs, engine/src/commands/doctor.rs (omarchy probe only),
engine/src/config.rs, docs/user/{en,de}/06-configuration.md. **Not**
capture.rs, reconcile.rs, collectors/mod.rs.

## Goal

(a) A capture from ssh, cron or any environment without `OMARCHY_PATH`
no longer degrades the plugins collector ("omarchy plugin list --json:
OMARCHY_PATH is not set"). (b) Desktop entries under
`~/.local/share/applications` are watched by default.

## Inputs

Test-host finding (0.1.3): non-interactive ssh capture degraded the
plugins collector. engine/src/sys.rs (run helpers, Drain threads),
engine/src/dossier/query.rs:50 (existing `/usr/share/omarchy` default),
engine/src/collectors/omarchy.rs (`$OMARCHY_PATH/version` read),
engine/src/commands/doctor.rs (~line 758, omarchy probe), engine/src/
config.rs (`DEFAULT_WATCH_PATHS`), engine/src/collectors/config.rs header
(scope changes are no additions), engine/src/commands/init.rs (wizard
writes `watchPaths` explicitly).

## Outputs

- (a) One constant + helper in sys.rs (reusing the query.rs default):
  children that run Omarchy commands get `OMARCHY_PATH` via
  `Command::env` only when it is unset or empty; a set value is trusted
  like PATH. Never `std::env::set_var` (unsafe in edition 2024, racy with
  the Drain threads). Route plugins.rs, omarchy.rs (version read),
  query.rs and the doctor probe through it. Tests with a stub `omarchy`
  that fails without the variable. `seldon watch` never runs collectors —
  say so in the handover, no change there.
- (b) `~/.local/share/applications` in `DEFAULT_WATCH_PATHS`;
  `mimeinfo.cache` (rewritten by update-desktop-database on many package
  transactions) excluded by name the way the plugins dir is, or justify
  why not. A path entering the scope records no addition (test). Guide 06
  en/de: existing configs written by the wizard keep their list; give the
  line to add.
- SPEC-ENGINE sentence(s); CHANGELOG lines.

## Acceptance

`just check` 0; mutants listed; a live capture over ssh on the test host
without `OMARCHY_PATH` shows the plugins collector ok (the orchestrator
runs it if the worker cannot). Review: stage 1 Opus.
