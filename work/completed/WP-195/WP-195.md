# WP-195 — Supply chain: Dependabot, no network crate in the engine, the AUR package in a container

Part 1 0.2.x; part 2 when the AUR package `jax-seldon` exists. Origin:
study of Tom Ballard's Omarchy work (2026-10-09,
`jax-seldon-private/study-tcballard/`), operator decision E70; Dependabot
was already approved on 2026-10-06 and never set up. Ideas only, no code
taken.

Role: Scaffold (Opus). Small. Reviewer: Opus; Fable stage 2 for part 2
(release workflow). No ADR.

**Problem.** Action pins and crates are refreshed by hand; the operator
has to remember. AGENTS.md §7 says "No async runtime. No network." — no
test proves it, so a new dependency could pull a network stack unnoticed.
The release builds a package but never installs and removes it.

**Goal.** Updates arrive as reviewable PRs; a network crate or `std::net`
in the engine turns `just check` red; later, the AUR package is proved to
install and remove cleanly.

**Do (part 1).**
- `.github/dependabot.yml`: `github-actions` (directory `/`, weekly, one
  `groups:` block so all action bumps arrive in one PR and
  `tests/release/workflow-pins.test.sh`'s one-pin-per-action rule holds;
  the SHA pins keep their `# vX.Y.Z` comments) and `cargo` (directory
  `/engine`, weekly, grouped minor/patch). Check whether Dependabot reads
  the `container:` image digests in workflows; if not, the manual refresh
  in `packaging/README.md` stays and says so.
- `scripts/check-no-network.sh` in `check-packaging`: reads `cargo tree
  --manifest-path engine/Cargo.toml --locked --offline -e normal,build
  --all-features` (the shipped graph; `jsonschema` is a dev-dependency
  and out of it) and fails on a denied crate: `reqwest`, `hyper`, `h2`,
  `tokio`, `async-std`, `ureq`, `curl`, `isahc`, `rustls`, `native-tls`,
  `openssl`, `openssl-sys`, `hickory-*`/`trust-dns-*` (the list in the
  script with one comment). `mio` is allowed: `notify`'s poll loop
  (feature `watch`), no sockets used. It also fails on `std::net`,
  `TcpStream`, `UdpSocket` or `TcpListener` in `engine/src`.
- `tests/release/no-network.test.sh`: the script reads the tree from a
  file in test mode; mutants with `reqwest` in a fake tree and `std::net`
  in a scratch source file turn it red (no network needed).
- `packaging/README.md` and `docs/TESTING.md`: what Dependabot does, how a
  Dependabot PR is reviewed (an allowed crate only, AGENTS.md §7).
- The operator enables Dependabot alerts and security updates in the
  repository settings (`jax-seldon-private/study-tcballard/BRANCH-PROTECTION.md`).

**Do (part 2, deferred until the AUR package exists).** In the release

## Also (orchestrator, 2026-10-09 night)

The CI `check` job failed twice on PR #7 before any step ran: Docker Hub's
unauthenticated pull limit for `archlinux@sha256:…` on GitHub's shared
runners ("toomanyrequests"). Make the pinned build image independent of
Docker Hub's anonymous limit: mirror the pinned digest to GHCR in a
workflow step that runs only when the digest changes (same digest, GHCR
as the pull source), or pull with a read-only token. A token is a repo
secret and needs the operator; prefer the GHCR mirror (`packages: write`
only in the mirroring job).
