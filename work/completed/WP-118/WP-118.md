# WP-118 — Wizard, installer and docs texts (UX review, 0.1.4)

Role: Engine Dev + Docs (Opus, high). Ships in 0.1.4, after WP-116
(shared files: the wizard, guides 04/06/11). Text-level; no contract
change.

## Goal

The terminal side of the first setup says what it does in Omarchy's
style and asks nothing a new user cannot answer that 0.1.4 can avoid.

## Inputs

The UX review's 0.1.4 list items 1, 2 and 4 (private field notes;
summarised here):
- `seldon init` wizard (engine/src/commands/init.rs, setup.rs):
  `BACKFILL_NOTE` no longer promises "the bar pill starts red, often with
  crises" (ADR-0028); the theme-hook prompt is a note plus a short
  question (the long prompt printed twice at narrow widths); the
  `omarchy-agent` harness option appears only when the kit directory
  exists and is labelled for what it is (a private kit, not Omarchy's
  agent); the result summary shrinks to about six lines, "Next steps"
  only when something is left to do.
- `packaging/install.sh`: an announce line first (what it installs,
  where, how it checks); context-aware "Next steps": no `seldon init`
  when a config exists, no plugin add line when the plugin is installed.
- Docs en/de: guide 01 step 2 and its summary block; guide 10 banner
  table; guide 11 "plugin 0.1.0 users update the plugin first" and
  "Omarchy shows the plugin's diff on update — confirm it"; the release
  notes template line; plugin README *States*/*Troubleshooting*.
ADR-0033 (90-day backfill default) is **not** in this WP — it lands with
the 0.1.5 setup flow (WP-119); keep the wizard's backfill question but
fix its text.

## Acceptance

Tests pin the new texts (wizard prompts, the kit option hidden without
the kit, the summary, installer next steps in both contexts); shellcheck
in CI for install.sh; `just check` 0. Review: stage 1 Opus.
