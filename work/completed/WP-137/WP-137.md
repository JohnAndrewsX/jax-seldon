# WP-137 — A transaction's packages in the Changelog detail

Ships in 0.2.0 on the integration branch `next` (branch from and merge into `next`). Operator decision 2026-10-07 after the comparison with the Omarchy plugin "What changed" (nejcc.what-changed, MIT). The idea is taken, not its code: write our own.

Role: Plugin Dev with a check of the engine data (Opus, high). Small. Order: W4, second.

**Goal.** Selecting a pacman transaction in the Changelog shows every
package in it:
- ↑ upgraded, ↓ downgraded, + installed, − removed, ↻ reinstalled;
- old → new version;
- the command that started it.

A transaction that did not complete (interrupted or failed) is marked in
the urgent style, in the row and in the detail.

**Inputs.**
- engine/src/collectors/pacman.rs (txId, `meta.command`, interrupted
  handling).
- The index events.
- WP-122's Changelog and event detail.
- SPEC-PLUGIN.
- Contract 2 (ADR-0035) and ADR-0038.

**Outputs.**
- If the index already carries what is needed (events by txId, versions,
  status), this is a plugin-only change. If not, use the smallest optional
  field under ADR-0035 §6 / ADR-0038, as a contract question first.
- Tests:
  - harness cases for a mixed transaction, an interrupted one and a
    downgrade;
  - fixture rows for each.

**Acceptance.**
- `just check` is green.
- The three themes, at 50 % and 100 %.
