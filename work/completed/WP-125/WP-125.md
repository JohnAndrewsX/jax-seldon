# WP-125 — The graph

Ships in 0.2.0 on the integration branch `next` (branch from and merge into `next`). Plan: decisions/ADR-0034-desk.md and the 0.2.0 plan (orchestrator's private notes); the prototype is the spec of look and behaviour (path in the brief).


Role: Plugin Dev (Opus, high). Wave 3, after WP-120 and WP-121.

**Goal.** Section 8 shows the machine's memory as a growing network from
the index alone, with drag, pan, zoom, hover, replay, and inside the
performance budget on the shell thread.

**Inputs.** ADR-0034 §5; prototype `graph()` (forces, radii, colours by
kind, hover card, replay, cluster-free reference); `Model.js` chart
patterns (`ChartCanvas.qml`, `aggregationCount`); `fixtures/
index.sample.json` v2 (`decisions[].cases`); SPEC-PLUGIN §7 (theme
colours: accent = case, ok-ish = area → use `Color.accent`,
`Color.foreground` opacities, `Color.urgent` for crisis; the prototype's
`--ok`/`--notice` have no shell token — pick foreground opacities and
shape, as the Timeline's A12 markers do).

**Outputs.**
- `Model.js`: `graphBuild(index, cap)` (nodes, edges, day index, folding
  beyond 400), `graphStep(state, dtBudget)` (force step, alpha decay,
  pinned drag node), `graphPick`, `graphInfo`; pure, unit-tested under
  node, benchmarked in `model.bench.js` (≤ 8 ms per step at 400 nodes on
  the dev host).
- `components/graph/GraphCanvas.qml` + `sections/Graph.qml`: Canvas,
  Timer ≤ 30 Hz, sleep after 200 ticks, wake on interaction, nothing
  while hidden; pan/zoom/drag/hover; legend; date slider + Play; hover
  card with "Open case" → section 3; footer "newest N events / M
  completed cases in the index".
- `Desk.view()` reports `graph: {nodes, edges, folded, ticks, tickMs,
  sleeping}`; harness steps `graphPlay`, `graphCut:<day>`.
- SPEC-PLUGIN §5 section 8; guide 05 en/de paragraph.

**Acceptance.** `just check` 0; unit tests for build/fold/edges/day
index; harness: on the fixture the graph settles and sleeps, `tickMs` ≤
8 on every reported tick, replay from day 0 to the last day adds nodes
monotonically, hover and open-case work, no tick while another section
is shown; theme sweep shot in three themes; **measured on the test
host** with a backfilled 90-day logbook (ADR-0033 default) — if `tickMs`
exceeds 8, the handover proposes §5's escalation and the WP is sent back
rather than merged with a slower graph. Review: stage 1 Opus.
