# WP-174 — Readers never hang on a FIFO or a device in the logbook

0.2.0, before the tag. From the Fable stage-2 review of WP-171
(2026-10-09, finding N1); pre-existing, not introduced by WP-171.

Role: Engine Dev. Small. Reviewer: Opus; Fable stage 2 short (engine core).

**Problem.** Writers refuse a linked or non-regular logbook file (WP-171),
but some readers open files without checking their type or size:

- a FIFO at `ledger/<month>.jsonl` blocks `seldon status` and
  `seldon doctor` (`engine/src/ledger.rs:121`, `std::fs::read`);
- a FIFO at the logbook's `AGENTS.md` hangs `doctor` and `capture`
  (`engine/src/rules.rs:62`, `engine/src/commands/doctor.rs:1460`);
- a FIFO at `STATUS.md` or `DECISIONS.md` hangs `doctor`
  (`doctor.rs:941`);
- a link to `/dev/zero` at any of these reads until memory runs out.

So `doctor` can hang before its `layout` row can name the problem.
Journal days, cases and decisions are already type-checked.

**Do.**

- One shared read helper for logbook files: open without following a
  final link where the writer refuses one (or check the type on the open
  fd), refuse anything that is not a regular file, and read with a size
  cap (name the cap; a ledger month and AGENTS.md need different caps or
  one generous cap). Route every reader above (and any other `read`/
  `read_to_string` of a logbook path you find) through it.
- A refused file is a clear error or a `doctor` row, never a hang.
  `doctor` must still reach its `layout` row.
- Tests: FIFO and `/dev/zero` link at each path above → the command
  ends within a time limit with the reason; a regular file reads as
  before. A grep test that new logbook reads use the helper.
- SPEC-ENGINE §3 one paragraph; CHANGELOG.

**Acceptance.** The tests; `just check` green; no reader in
`engine/src/` reads a logbook path without the helper (grep test).

**Inputs.** The Fable packet
`jax-seldon-private/review-0.1.1/handovers/WP-171-stage2-fable.md` (N1),
WP-171's `layout.rs` and `open_append_nofollow`, `engine/src/ledger.rs`,
`engine/src/rules.rs`, `engine/src/commands/doctor.rs`, ADR-0049.
Depends on WP-171 (merge it first).
