# WP-047 — Instructions for AI agents: llms.txt, AGENT-GUIDE, logbook AGENTS.md template

## Goal
An AI agent that is handed one of the two repository URLs, or that is
started inside a Seldon logbook, finds complete, correct instructions
without a human explaining anything: what Seldon is, how to work a case,
which commands are safe, what is forbidden.

## Inputs
AGENTS.md (the team rulebook — stays as it is; this WP adds the
user-agent view beside it), README.md, docs/CONCEPT.md, docs/SPEC-ENGINE.md
§3 §8 (commands, hooks), docs/SPEC-LOGBOOK.md, docs/CONTRACT.md, the
logbook templates in engine/src/logbook/ (the generated `AGENTS.md` of a
new logbook, `memory/lessons.md`, case and decision templates), the
Claude Code harness install (`.claude/settings.json` hooks written by
`init --harness claude-code`), work/completed/PHASE-0-EXIT-transcript.md
(F3: Claude Code worked a case from the logbook's AGENTS.md alone),
the llms.txt convention (https://llmstxt.org, read-only), plugin/README.md.

## Outputs
- `llms.txt` at the repository root (and copied into the plugin split by
  the release workflow if the convention expects one per repo — decide,
  state it): one page — what Seldon is, the two parts, where the docs
  live (links), the safe read-only commands, the writing commands and
  when an agent may use them, what is forbidden (never edit the ledger,
  never delete the logbook, never run the engine against another user's
  logbook), where the human-facing docs and the specs are.
- `docs/AGENT-GUIDE.md`: how an agent works inside a Seldon logbook —
  session start (read `AGENTS.md`, `memory/lessons.md`, `STATUS.md`,
  active case), planning a case before changing the machine, zones and
  risk, `seldon log`/`event`/`plan`/`decide`/`open`, the hooks and what
  they record, drift and how to explain it, ending a session, a worked
  example (the Phase 0 exit case), and a "do not" list; English.
- The generated logbook `AGENTS.md` (en and de templates) reviewed and
  extended with the same content in short form. **No `CLAUDE.md` shim**
  (operator decision 2026-10-02: Claude Code now reads `AGENTS.md`
  itself; one file, one source of truth). If the init-skeleton golden
  changes because of the template text, update it.
- README.md section "For AI agents" (three lines + links); plugin
  README gets the same pointer.
- A test that the generated logbook's `AGENTS.md` (en and de) contains
  the agent rules' key sections; docs/TESTING.md row.

## Acceptance tests
- `just check` exit 0.
- A fresh `seldon init` (scratch) yields the extended `AGENTS.md`; the
  texts render on GitHub; `llms.txt` validates against the convention's
  structure (title, summary, sections with links).
- A reviewer reads `llms.txt` and `AGENT-GUIDE.md` as an agent would and
  can list the safe commands and the forbidden actions without the specs.

## Constraints
English for everything public; German prose only in the de template;
no change to engine behaviour (template text only); a guard block is
reported, never worked around.
