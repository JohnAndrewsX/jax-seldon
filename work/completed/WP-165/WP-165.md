# WP-165 — Show the packages pacman ignores (IgnorePkg names)

Ships in 0.2.x on `next`. Operator decision 2026-10-08 (S9). AGENTS.md §6
is amended for it: names only.

Role: Engine Dev + Plugin (Opus, medium). Small.

**Do.**
- Read only the `IgnorePkg` and `IgnoreGroup` names from `/etc/pacman.conf`
  and `/etc/pacman.d/*.conf` (the `Include` chain as pacman reads it), no
  other key or value.
- The index carries them (optional field under an ADR per ADR-0035 §6, or
  0.3 if the contract is closed by then); the desk's System section lists
  them with one line why it matters ("these never update").
- A change of the list is an event (attention).

**Acceptance.** Tests with includes, comments, several lines; `just check`
green.
