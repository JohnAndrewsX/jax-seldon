# WP-043 — Import the operator's omarchy-agent vault into the Seldon logbook (dry run first)

## Goal
The operator's earlier logbook (the `omarchy-agent` kit's Obsidian vault)
lands in the Seldon logbook with its history intact: cases, journal,
decisions and knowledge, dated as they were, never silently merged.
Operator decision 2026-10-02: option A (importer, dry-run report first).

## Inputs
The vault copy under the operator's backup (path in memory/local.md,
never committed): `STRUCTURE.md` (the kit's map), `pipeline/cases/*.md`
and `archive/cases/*.md` (frontmatter `id, type: case, title, status:
new|planned|in-progress|verification|done|dropped, zone, risk, priority,
created, closed, tags`; sections Auftrag / Plan / … in German),
`pipeline/inbox/`, `pipeline/templates/`, `journal/YYYY-MM.md` (one file
per month, one entry per session), `knowledge/{omarchy,arch,hyprland,
claude-code,lessons}/*.md` and `knowledge/scripts.md`, `system/*.md`
(the kit's dossier incl. `deviations.md`), `Dashboard.md`.
docs/SPEC-LOGBOOK.md (Seldon layout: work/{queued,active,completed,
dropped}, journal/YYYY/YYYY-MM-DD.md, decisions/, memory/, system/
fences, areas/), docs/SPEC-ENGINE.md §3 §6 §7 (redaction), engine/src/
logbook/ (case model, lossless frontmatter, transitions), engine/src/
commands/{plan,log,decide}.rs, ADR-0007 (English headings), ADR-0012
(event kinds), memory/pitfalls.md.

## Outputs
- `seldon import omarchy-agent <vault-dir> [--dry-run] [--json]`
  (default is dry run; `--apply` writes):
  - **Cases:** each kit case → a Seldon case file with the same id when
    it does not collide (else `C-YYYY-NNN` renumbered with the original
    id in `tags` and the body), status mapped (`new|planned` → queued,
    `in-progress` → active? no: imported cases are never active —
    `in-progress`/`verification` → queued with a note, `done` →
    completed, `dropped` → dropped), zone/risk/priority kept, `created`/
    `closed` kept, German sections mapped to Seldon's (`Auftrag` →
    Intent, `Plan` → Plan, the rest under `## History` verbatim), an
    `import` note in the Log with the source path; one ledger event
    `note` per case (`actor: human`, `meta.import: omarchy-agent`,
    `ts` = created).
  - **Journal:** month files split by their session headings into
    `journal/YYYY/YYYY-MM-DD.md` entries (append under a `## Imported
    from omarchy-agent` heading when the day exists).
  - **Knowledge:** `knowledge/<topic>/*.md` → `memory/<topic>.md`
    sections (append, source line per section); `knowledge/lessons/` →
    `memory/lessons.md`.
  - **Deviations:** rows of the kit's `system/deviations.md` → user rows
    in Seldon's `deviations.table` (path, reason, date, no case) when
    the path is not already listed; other `system/*.md` are not imported
    (Seldon generates its own dossier).
  - **Inbox and Dashboard:** listed in the report, not imported.
  - **Redaction** (SPEC-ENGINE §7) over every imported line; private
    paths rewritten to `~`.
  - **Dry-run report** `outputs/IMPORT-omarchy-agent.md`: counts per
    kind, the id mapping table, collisions, skipped files with reasons,
    redaction hits; `--apply` writes files, one autocommit `seldon:
    import omarchy-agent`, index rebuilt; idempotent (a second `--apply`
    changes nothing; marker file `.seldon/imports/omarchy-agent.json`).
- Tests via common::Env with a small synthetic vault fixture under
  fixtures/vaults/omarchy-agent/ (built from the kit's templates, no
  operator content); docs: SPEC-ENGINE §3 line, SPEC-LOGBOOK §3 note,
  TESTING.md.

## Acceptance tests
- `just check` exit 0; dry run on the fixture vault matches a golden
  report; `--apply` twice → second run "nothing changed".
- Dry run on the operator's real vault copy (read-only input, output to
  a scratch logbook copy, XDG redirected) completes with 0 errors; the
  operator reads the report before any `--apply` on `~/Seldon`.

## Constraints
The real vault is read-only input; the operator's `~/Seldon` is touched
only by the operator-run `--apply`; no new crates; a guard block is
reported, never worked around.
