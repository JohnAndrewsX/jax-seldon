# WP-041 — Plugin README, preview.png, security section, keybinding docs

## Goal
The plugin is ready for the marketplace listing: its README follows the
Omarchy plugin template, a preview image shows the panel and the Prime
Radiant, the security section says exactly what the plugin runs and reads,
and the keybindings are documented for users.

## Inputs
docs/SPEC-PLUGIN.md (all; §5 keys, §8 IPC and the suggested binding, §9),
docs/CONTRACT.md (what the plugin reads and the fixed command forms),
decisions/ADR-0004, ADR-0009, ADR-0016, plugin/README.md (current),
plugin/manifest.json, `$OMARCHY_PATH/shell/plugins/README.md` and the
built-in plugins' READMEs (the template; code is truth), the marketplace
guidance at https://plugins.omarchy.org/develop.html (read-only web
reference; cite what you rely on), work/completed/WP-030/HANDOVER.md and
work/completed/WP-031/HANDOVER.md (renders, harness `OVERLAY_SHOTS`),
tests/plugin/panel-view.sh and overlay-view.sh (offscreen renders),
memory/omarchy-shell.md.

## Outputs
- `plugin/README.md` rewritten along the marketplace template: what it
  is, requirements (engine from the AUR, `omarchy pkg aur add jax-seldon`),
  install (`omarchy plugin add https://github.com/JohnAndrewsX/jax-seldon-plugin.git`
  per ADR-0009; dev install by copy), the pill, the panel's six tabs with
  the keyboard table (digits, Tab, h/l, n/e/c/+/x/a/d, Esc, the two-press
  arming), the Prime Radiant (open via IPC/middle click, periods, charts,
  hover, The Plan), settings (`captureIntervalMin`, `wipLimit`), states
  (engine missing / not initialised / index missing / stale, each with its
  one-click fix), IPC targets and the suggested user binding, a
  **Security** section (runs unsandboxed in the shell; reads only
  `index.json` and the files it points to; executes only the fixed `seldon`
  argument lists listed in CONTRACT.md plus `wl-copy`; never shell
  strings; no network; no units; no binaries in the plugin folder;
  dev-mode read-only), troubleshooting, project home and licence.
- `plugin/preview.png` (and the source renders under
  `plugin/docs/` or `docs/images/` — decide, state it): a composed image
  of the bar pill + panel (Today tab) and the Prime Radiant at 1920×1080
  in one Omarchy theme, produced from the offscreen harnesses
  (`OVERLAY_SHOTS`, the panel equivalent) on the sample index; no live
  screenshots needed (test host locked). Composition with ImageMagick
  only if installed (check `command -v magick convert`); otherwise two
  images and a README note.
- Keybinding docs: a `docs/KEYBINDINGS.md` (or a README section — pick
  one and link the other) listing panel keys, overlay keys, the IPC
  commands and the suggested Hyprland binding (not installed by the
  plugin).
- `manifest.json`: `description` and `barWidget.description` reviewed
  for the listing; no id/kind changes.
- `omarchy plugin validate plugin/` and qmllint still pass; no symlinks;
  `README.md` renders on GitHub (check headings/tables).

## Acceptance tests
- `just check` exit 0.
- README sections match the template order of the built-in plugins;
  every key in SPEC-PLUGIN §5 appears in the keyboard table; every state
  in AGENTS.md §7 has its fix documented.
- `plugin/preview.png` exists, ≤ 1 MB, shows the panel and the overlay.
- Security section lists exactly the commands in CONTRACT.md (cross-check
  by grep over `plugin/Service.qml` for `seldon` argv arrays).

## Constraints
Docs only plus the preview; no plugin logic changes (a wording fix in a
UI string is fine, say so). Test host untouched (locked). No installs on
the dev host; a guard block is reported, never worked around.
