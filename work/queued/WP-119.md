# WP-119 — Set up Seldon end to end (UX review flow, 0.1.5)

Role: Engine + Plugin + Docs (Opus, high). 0.1.5. No contract change
expected (state the opposite in the handover if found).

## Goal

A new Omarchy user goes from "plugin added" to "Seldon is recording" by
clicking through one card, answering no question, typing one password
only for the optional snapshot step.

## Inputs

The UX review's 0.1.5 list (private field notes); ADR-0033 (90-day
backfill, automatic "before Seldon" baseline, no question); ADR-0026
(snapshot read grant); ADR-0027, ADR-0028, ADR-0030, ADR-0031; WP-117's
terminal pattern.

## Outputs

- One setup card with three steps (engine → logbook → snapshots), auto
  re-probe after each, *Not now* for the snapshot step; the three banner
  states stay the model behind it (SPEC-PLUGIN §5 "Setup card").
- `seldon init --defaults` (the panel's path: zero questions, ADR-0033);
  plain `seldon init` asks only the location; `seldon init --ask` is the
  full wizard; Obsidian detected rather than asked.
- A first-run card on Today ("Seldon is recording … nothing to do"),
  zero stats dimmed.
- Guide 01 rewritten plugin-first; the terminal path becomes the
  alternative section.

## Acceptance

Harness cases for the card's states and transitions; engine tests for
`--defaults` (no prompt reads stdin), `--ask`, the 90-day backfill and
its dismissal; live check on the fresh test host from a clean home,
counted per ADR-0027 §1. Review: stage 1 Opus, stage 2 Fable.
