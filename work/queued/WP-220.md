# WP-220 — WP-209 follow-ups: a privileged wrapper after a skip, sudo -S in substitutions, timing rows

A 0.4.x patch. From the WP-209 reviews (2026-10-13: Opus stage 1 round 3
O1–O3, Fable stage 2 instructions 1–4). None blocked 0.4.0.

Role: Engine Dev (Opus, high). Reviewer: Opus, then Fable (security).

**Do.**
- **Wrapper after a skip (O2).** Since WP-209 a line with a substitution
  nested deeper than 16 is read only up to the skip (fail closed), so a
  privileged command after it is not recorded. When a line is too deep,
  scan its unread tail for a wrapper word (`sudo`, `doas`, `pkexec`,
  `run0`) at a word boundary; if one is found and the line yields no other
  privileged record, write one record with that word as subject and
  wrapper and the command `<word> ‹redacted›`. No text from the tail, no
  schema change. (The wider variant, every too-deep line recorded as
  privileged without a wrapper word, needs the operator's decision; do not
  build it.)
- **`sudo -S` in a substitution.** ADR-0039 §2 still says "a `sudo -S`
  inside `$(…)` is not seen"; `password_on_stdin` now reads the opened
  segments. A new amendment note names that sentence. Add a hooks row:
  `x=$(echo PW | sudo -S lpadmin -x a)` → `lpadmin ‹redacted›`.
- **Timing rows without a budget (O1).** In `check-perf`: the worst shape
  below the depth limit (16-deep nests read in full, then one skip, in
  `sh -c`; 55.7 ms at 128 KB) and `sh -c` nested to `NESTING_MAX`, each
  script re-parsing a 16-deep nest behind a double-quoted outer. Logged,
  not budgeted; their budget joins WP-157's pending per-medium decision.
  No per-line time cap and no lower depth limit.
- **Hardening.** `ShellLine` carries the skip index; the two readers of
  `line.text` (`secret_in`, `names_skipped_path`) say in a comment that they
  read the unread tail only to mask more. A hooks row with text after a
  skipped `<(` (O3).

**Acceptance.** A test row and a mutant per item; SPEC §8 and the new
ADR-0039 note match; `just check` green; evidence words in the handover.
