# WP-151 — Removed stock Omarchy packages in the dossier and REBUILD

Ships in 0.2.x. Source: the study of omarchy-troubleshooter and omarchy-setup (private, in the orchestrator's notes; ideas only, no code taken). Operator decision 2026-10-07. Seldon reads, records and proposes; the agent does the work. (S3, must have)

Role: Engine Dev (Opus, medium). Small.

**Goal.** A fresh install that follows REBUILD.md does not bring back the
packages the user removed.

**How.**
- From the `omarchy-base.packages` read WP-036 already does, list the
  stock packages that are not installed.
- They go into the dossier as `packages.removedBase`, and into REBUILD.md
  as one `omarchy pkg drop …` line. The line goes through
  `rebuild::shell_arg` and is never run by Seldon.

**Acceptance.**
- A fixture with two removed stock packages → the dossier fact and the
  REBUILD line.
- Idempotent.
- `just check` is green.
