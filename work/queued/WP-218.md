# WP-218 — the fast path for hook session-start and hook generic

0.3.x patch (no surface change, no budget change). From the WP-216
review (2026-10-13): the check-perf rows `hook session-start` and `hook
generic` for an unrelated session take about 0.96–1.03 ms on the dev host
against ADR-0030's 1 ms budget; about 0.23 ms of that is clap's argument
parsing. `hook claude-code` already has WP-092's fast path and takes about
0.8 ms.

Role: Engine Dev (Opus, high). Reviewer: Opus.

**Do.** Give `hook session-start` and `hook generic` the same fast path
as `hook claude-code` for the unrelated-session case (decide before clap
whether the hook has anything to do), with identical output and exit
codes in every case the full path handles; no budget moved.

**Acceptance.** Both rows pass `just check-perf` on the dev host with
margin (report the medians); a differential test full path vs fast path
over the hook test inputs; `just check` green; evidence words in the
handover.

**Inputs.** `engine/src/commands/hook*`, WP-092's fast path, ADR-0030;
`justfile` (`check-perf`); private `review-0.1.1/handovers/WP-216-review-1.md`
and `gates/rv-216/profile.log`.
