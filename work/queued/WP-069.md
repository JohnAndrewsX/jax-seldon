# WP-069 — config collector: scope changes, default skips, home-relative paths, no rehash of unchanged files, no repeat after a failed cursor save

Role: Engine Dev (Opus, high). Size: L. Wave: 4. Depends: WP-064
(`sys.rs`), WP-062 and WP-060 (user guide 06).
Findings: F-101 (+ merged F-451), F-250, F-544, F-100 (config half; the
plugins half is WP-073), F-402.

## Goal

- **F-101 / F-451** — `manifest.json` stores the effective watch scope per
  generation; a narrowed scope prunes out-of-scope paths silently with
  one notice line instead of `config-remove` events; a widened scope
  baselines new paths without a flood (collectors/config.rs ~555-600).
- **F-250** — default `skipPaths` for frequently rewritten plugin state
  and history files under `~/.config/omarchy/*` (config.rs ~265-272);
  `init`/setup output mentions `skipPaths`.
- **F-544** — relative config values and `$HOME` resolve against HOME
  (or are refused naming the key) instead of the process cwd
  (`Dirs::expand` ~154-165); the wizard stores input as `~/…`
  (init.rs ~628-641).
- **F-100 (config)** — config events are deduplicated against the ledger
  since `prev.checked`, like the other collectors, so a failed cursor save
  does not repeat them (capture.rs ~109-113 for context).
- **F-402** — a watched file whose size and mtime match the manifest
  reuses the stored hash (`scan.mtimes`); `sys::sha256` hashes without
  copying the input (~196).
