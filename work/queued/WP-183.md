`docs/skills/omarchy-ux/SKILL.md`, inside its ≤ 100-line budget:
- `textFormat: Text.PlainText` at every sink of external text, including

  (WP-126's index limit), a deadline for each process;

  banners' constant installer until the AUR package exists (ADR-0024;
  WP-042);
- privilege wording true and in the store scanner's recognised form
  (WP-042), never a denial that is not literally true;
- no agent files (`AGENTS.md`, `CLAUDE.md`) in the shipped plugin tree;
- a shortened preview never changes what an action does.
