# WP-036 — Dossier follow-ups: Omarchy base split, `packages.explicit` in templates and fixture, deviation case fill

## Goal
`outputs/REBUILD.md` separates what Omarchy itself installs from the
user's own additions, every new or sample logbook carries the
`packages.explicit` fence from the start, and a deviation row whose case
cell is empty gets the case from a later cased event.

## Inputs
work/completed/WP-035/HANDOVER.md (decisions 2, 4, 5 and the review's
non-blocking items), engine/src/dossier/{mod,query}.rs, engine/src/rebuild/
{mod,render}.rs, engine/src/logbook/templates (init skeleton, en/de),
fixtures/logbook/system/packages.md, engine/tests/golden/{dossier,REBUILD}.md,
`$OMARCHY_PATH/install/omarchy-base.packages` and `omarchy-other.packages`
(read-only; the format is one package per line, comments allowed — verify
on the host), docs/SPEC-ENGINE.md §3 (`dossier`, `rebuild`), docs/SPEC-LOGBOOK.md §3.

## Outputs
- `packages.explicit` lines gain an origin class: `omarchy-base` when the
  package is listed in Omarchy's base or other package list at dossier
  time (read-only file read, path from `$OMARCHY_PATH`, override
  `SELDON_OMARCHY_PACKAGES` for tests, fixture copies under
  `fixtures/logs/omarchy-packages/`), otherwise `user`. Absent lists →
  every package `user` with one warning.
- `rebuild` §2 "Before the logbook" lists only `user` packages in the
  `sh` block and states the count of Omarchy base packages in one line
  ("N more come with Omarchy <version>"); the WP-032/035 trace tests
  updated; golden updated.
- Init templates (en/de) and `fixtures/logbook/system/packages.md` carry
  an empty `packages.explicit` fence under its heading; the init-skeleton
  golden and the dossier golden updated; `fixtures/index.sample.json`
  unchanged (verify with the validator).
- `deviations.table`: a row whose case cell is empty gets the case of a
  later cased config event on that path; nothing else in the row changes
  (reason, date and the user's text stay). Spec sentence in SPEC-LOGBOOK
  §3 adjusted ("never changes an existing row" → "changes only an empty
  case cell").
- Tests for each item through `common::Env` with shims; idempotent second
  run; docs/SPEC-ENGINE §3 and SPEC-LOGBOOK §3 updated.

## Acceptance tests
- `just check` exit 0.
- On the fixture with shims: `packages.explicit` shows both origin
  classes; REBUILD.md's "Before the logbook" lists only `user` packages
  and the base count line; second run "nothing changed".
- `seldon init` skeleton contains the fence in both languages.

## Constraints
Read-only host access only (a file read under `$OMARCHY_PATH`); no
package-manager or service-manager command typed by the worker; no new
crates; keep to engine/src/{dossier,rebuild,logbook/templates}, tests,
fixtures/logbook/system, docs.
