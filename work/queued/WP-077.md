# WP-077 — case saves prepared before the ledger write; escaped validation errors

Role: Engine Dev (Opus, high). Follow-up from the WP-066 review. After
wave 5; independent of WP-073/074/075.

## Goal

A refused case save never leaves a ledger note or journal entry behind,
and validation errors never print raw control characters.

## Inputs

engine/src/commands/{log,event,hook,drift}.rs (the four callers that
emit a ledger line, then write the journal, then save the case),
engine/src/model/case.rs (`update` returns a refusal since WP-066),
engine/src/journal.rs (`journal::prepare` is the template),
engine/src/model/{case,decision}.rs, journal.rs, import/omarchy_agent.rs
(error messages that embed an id or value), engine/src/commands/plan.rs
(`plan list` exits 1 on one invalid case).

## Outputs

`CaseFile::prepare` (a dry-run `model::update` on a clone) called before
the ledger write in all four callers, with a test per caller that a
refused save writes nothing; validation errors format ids and values
with `escape_debug()` (test with an ESC sequence); `plan list` reports
an invalid case as a warning line and lists the rest (test); SPEC-ENGINE
§3 sentence; CHANGELOG lines.

## Acceptance

`just check` 0; mutants per item in the handover.
