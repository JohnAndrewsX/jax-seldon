# WP-186 — Bug reports remembered offline (E32, E35)

0.3. From the prototype 0.3 debate
(`jax-seldon-private/prototype-0.3/debate-2026-10-09/`, SYNTHESIS.md §3
NEW-11; items A5, A6, A10 prep); operator decisions E32 (a Reports area,
the engine stays offline), E35, E56 (a file with status, steps as notes,
`reopen` not `undo`, `defer` stays), E61.

Role: Engine + Plugin Dev (Opus, high). Medium–large engine, medium
plugin, SECURITY.md. Reviewer: Opus; Fable stage 2 (the link path).
ADR: "Bug reports" (Fable writes, next free ADR number; the operator
accepts): the file is truth, `seldon` notes as history, the verbs, no
generic undo, targets per Omarchy's `reporting.md`, the URL rule and the
browser path, PRO first (A10).

**Goal.** Bug reports the user filed are remembered as documents with a
status; Seldon never sends, fetches or posts.

**Do.**
- **Files.** `reports/R-YYYY-NNN-slug.md` in the logbook, created lazily;
  the frontmatter is the truth (status, target, url, links to crash, case,
  package); steps are `seldon` notes (ADR-0040 §2), never state kept in
  note text.
- **Verbs (E56):** `seldon report new --to <target>`, `filed <ID> --url
  <url>`, `close <ID> --as answered|fixed|declined -- <note>`, `defer <ID>
  --until <date>`, `reopen <ID>`; every one with `--json` and a CONTRACT
  row. **No generic `undo`** (the prototype's undo left a filed report
  without a link). `crash draft <crash>` (WP-185) fills a draft from the
  WP-166 analysis.
- **URL rule:** https only, no userinfo, a length cap, no control
  characters; the host is shown beside every link. The plugin opens it
  with a fixed argv chosen in the ADR (Omarchy's way of opening a URL,
  from `omarchy commands --json`); never a string built from logbook text
  (AGENTS.md §8).
- **Index:** `reports[]` mirrors `decisions[]` (no body, no history;
  WP-184).
- **Desk (PRO only, A10):** a Reports section (digit from WP-181's
  registry); "Wait another week" = today + 7 computed in the plugin;
  "due" by the plugin's clock. EASY may name an existing report read-only
  in a crash's details — later, after the beginner test.
- Fixture drafts are invented (one waiting, one due); the real Quickshell
  report's review (E35, 2026-10-15) is an orchestrator reminder, not this
  WP.
- SECURITY.md (plugin and repo): the link path.

**Acceptance.** `reports/` created lazily and older logbooks pass
`doctor`; the URL guard tested with userinfo, look-alike hosts, control
characters and over-long input; `close`/`reopen`/`defer` round trips;
invented fixture drafts render waiting and due; no network call anywhere
(test); `just check` green.
