Role: Engine Dev (Opus, high). 0.1.4 wave 2, depends on WP-087
(redaction is on the hook path). Files: engine/src/commands/hook.rs,
engine/src/commands/hook/, engine/src/index/ or rebuild paths the hook
calls; perf tests.

## Goal

The hook curl case measured 4.995 ms at 900 ledger lines under load 7–9
(WP-084 round 2); the cost is the rebuild, not redaction. Bring it to a
margin.

## Inputs

work/completed/WP-084/HANDOVER.md (measurement), the hook perf case in
engine/tests, `just check-perf`, docs/SPEC-ENGINE.md hook budget.

## Outputs

- Measurement fixed: the WP-084 case (900 lines, same machine, load noted)
  before and after. Target ≤ 2.5 ms for that case.
- Profile first, then change the dominant cost; behaviour unchanged
  (golden index output byte-identical).
- If an on-disk cache is introduced, say so: it raises the review to
  stage 2 and needs invalidation tests.

## Acceptance

stage 1 Opus (stage 2 Fable only with an on-disk cache).
