# WP-138 — Before init: a preview without memory

Ships in 0.2.0 on the integration branch `next` (branch from and merge into `next`). Operator decision 2026-10-07 after the comparison with the Omarchy plugin "What changed" (nejcc.what-changed, MIT). The idea is taken, not its code: write our own.

Role: Plugin Dev with an engine part (Opus, high). Medium. Order: W3, third. Fits WP-119 (the setup card).

**Goal.** Before the logbook exists, the desk is not empty. It shows the
last 7 days the machine already remembers on its own:
- pacman transactions;
- recently edited files under `~/.config`, mtime only.

It says plainly: "This is without memory: no who, no why, gone when the
logs rotate. Set up Seldon?" One click leads to the setup.

**Inputs.**
- WP-119 (setup card, `init --defaults`).
- AGENTS.md §3: the plugin reads only `index.json`, so the preview comes
  from the engine.
- WP-139 for the `~/.config` scan.
- The pacman collector.

**Outputs.**
- `seldon preview --json [--days N]`: read-only, no logbook, no state
  written.
- It returns a small JSON that follows a schema (new
  `schema/preview.schema.json`, under ADR-0035 §6 or its own short ADR).
- The plugin runs it with a fixed argv when the logbook is missing and
  renders it in Today.
- Bounded: 7 days, at most 200 rows, at most 0.5 s.

**Acceptance.**
- `just check` is green.
- A not-initialised harness case shows the preview and the setup click.
- Live on the fresh test host before `init`.
