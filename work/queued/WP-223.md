(2026-10-13/14: Fable stage 2 instructions 4–7; Opus N2, N3).

Role: QA / Scaffold (Opus). Reviewer: Opus, then Fable (supply chain).

- `plugin-qml`'s *Versions* step asserts that `pacman-conf --repo core

  versions (a pin comment or `assumptions.json`), so a moved snapshot is a

  through a crash in `png-ink.py` (N3).

  move to edge (R2-N2), as evidence.

  a private tool dir), so findings stop surfacing only in CI.

CI green; evidence words in the handover.
