# WP-148 — A rules digest for sessions outside the logbook

Ships in 0.2.x. Source: the study of the second predecessor "JARVIS" (private, in the orchestrator's notes; never in this repository). Operator decision 2026-10-07. (operator: "wie von dir vorgeschlagen")

Role: Engine Dev (Opus, medium). Small.

**Goal.** With the default hook scope, `memory/lessons.md` and the
machine's rules reach only agent sessions started in the logbook. An agent
started in `~/Work` (Omarchy's default, ADR-0030) never sees them.

**How.**
- The session-start hook prints a short digest for sessions outside the
  logbook: at most N lines, the newest lessons' titles, and the pointer
  `seldon memory show`. It is delimited as data (WP-058).
- No logbook text becomes an instruction; titles are redacted and clipped.
- The hook budget is kept.

**Acceptance.**
- Hook tests inside and outside the logbook.
- Budget (`just check-perf`).
- `just check` is green.
