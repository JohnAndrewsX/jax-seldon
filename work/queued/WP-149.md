# WP-149 — "Something is wrong": ask an agent to diagnose a symptom

Ships in 0.2.x. Source: the study of omarchy-troubleshooter and omarchy-setup (private, in the orchestrator's notes; ideas only, no code taken). Operator decision 2026-10-07. Seldon reads, records and proposes; the agent does the work. (S1, must have)

Role: Engine Dev with a plugin part (Opus, high).

**Goal.** The user writes one sentence ("Bluetooth drops since this
morning"). Seldon stores it as a journal note and offers *Ask agent to
diagnose*. That runs `seldon agent ask symptom <note-id> [--window 48h]`.
The prompt carries only the note id, the time window, the logbook path and
the skill guide (ADR-0036: ids, never text).

The agent reads the record and answers with an evidence proposal: the
events it suspects, each with `by <author>` evidence. A fix starts only
when the user turns the diagnosis into a case, which is the user's act.

**Inputs.**
- ADR-0036 (`agent ask`, proposals, evidence authors).
- ADR-0027 (a case the user started).
- WP-124 (triage) on `next`.
- The desk's Today section.

**Outputs.**
- `agent ask symptom`.
- A skill guide `symptom.md`.
- A proposal kind `suspect` (ADR amendment).
- The desk's journal field gets a *Something is wrong* toggle.

**Acceptance.**
- Prompt tests: only ids and paths.
- The proposal validates.
- The case is created only by the user's click.
- `just check` is green.
