# WP-152 — An opt-in hook after omarchy update

Ships in 0.2.x. Source: the study of omarchy-troubleshooter and omarchy-setup (private, in the orchestrator's notes; ideas only, no code taken). Operator decision 2026-10-07. Seldon reads, records and proposes; the agent does the work. (S4, nice to have)

Role: Engine Dev (Opus, medium).

**Goal.** `seldon init --update-hook` installs an Omarchy `post-update`
hook through `omarchy hook install` (Omarchy first; the same pattern as
`--theme-hook`). After `omarchy update` it runs one `seldon capture` and,
once WP-033 exists, a notification: "N overrides, M cases to re-check".
The desk then offers *Ask agent to re-verify*. The agent runs the checks,
never Seldon.

**Dependencies.**
- WP-033 (update impact).
- WP-145 (follow-ups) for the re-check list.

**Acceptance.**
- Install and remove are idempotent.
- A hook payload test.
- The hook budget holds.
- `just check` is green.
