# WP-156 — The desk steps aside for what it opens; one agent per case

Ships in 0.2.0 on the integration branch `next`. **Must fix before the
tag.** Source: the operator's live use on the test host, 2026-10-07 17:39,
case C-2026-005.

Role: Plugin Dev with a small engine part (Opus, high).

**What happened.** The desk is a full-screen overlay at 100 % width and
stays open.
1. "New case" with one sentence started an agent (17:39:15).
2. *Hand to agent*, armed twice, started a second one (17:39:40).
3. Another click started a third (17:42:01).
4. Three clicks on *Open in editor* opened three nvim windows (17:40:58,
   :41:00, :41:02).

Every window opened **behind the desk**, on the current workspace, so the
operator saw nothing and clicked again. All three agents were working the
same case and waiting for the user's R3 go in terminals nobody could see.

**Goal.**
1. **The desk hides when it opens a window.** After a successful launch of
   an agent (`agent start`, `agent ask`, `--new`), an editor (`open
   --editor`) or a terminal action, the desk hides, as Omarchy's menus do.
   Focus goes to the new window if the launcher tells us its address;
   otherwise Hyprland's normal focus applies.
2. **One agent per case.** `agent start <ID>` on a case whose launched
   session is still alive (track the launcher pid, or the window by
   app-id and title, in state) refuses with exit 1: "agent already working
   on C-…; focus it with …". `--again` starts another anyway.
   - The desk shows *Agent working* with *Focus* instead of a second
     *Hand to agent*.
   - The same rule applies to `--new`: starting an agent on a new case
     always makes a new case, so it is fine.
3. **No double launch.** While a launch is in flight the button is busy
   (the same pattern as capture).
4. **Opening the same file twice in the editor** focuses the existing
   window, or at least never opens two within 2 s.

**Inputs.** ADR-0030 (the launcher, `omarchy agent prompt`), ADR-0034
§1–§3 (the desk window), WP-121's desk shell, WP-122's Work section, the
engine's `agent start` and `open`, and Omarchy's launcher scripts (read
them: what can tell us the new window or pid).

**Acceptance.**
- Harness cases: launched → desk hidden; a second hand-off refused with
  *Focus*; double-click → one launch.
- Engine tests for the refusal and for `--again`.
- A live check on the test host: one click shows the agent terminal in
  front.
