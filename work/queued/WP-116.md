# WP-116 — The Seldon agent starts like the Omarchy agent (ADR-0030)

Role: Engine Dev + Docs (Opus, high). Ships in 0.1.4. After WP-111
(shared files: the skill, the session-start context, the guides). No
contract change.

## Goal

`seldon agent start` and the panel's New case open the agent exactly as
`omarchy agent prompt` does (same folder rule, flags, window), and Seldon
still records the session it launched — and only that one — through
user-wide hooks served by a launch marker `SELDON_CASE`.

## Inputs

decisions/ADR-0030-start-like-omarchy.md (normative, §1–§6),
ADR-0007, ADR-0027 §6/§8; `$OMARCHY_PATH/bin/omarchy-agent` and
`omarchy-agent-prompt`; Omarchy's agent skills under
`$OMARCHY_PATH/default/agents/skills/`; engine/src/commands/agent.rs
(`launch`), engine/src/commands/hook.rs (`in_scope`, settings install),
engine/src/commands/hook/context.rs, engine/src/commands/doctor.rs;
engine/assets/skills/seldon/; docs/SPEC-ENGINE.md §3/§8; docs/user/{en,de}/04, 05;
work/completed/WP-063, WP-094, WP-096 handovers.

## Outputs and acceptance

As ADR-0030 §6 (engine, skill, docs; acceptance items 1–6 as tests,
`just check` 0, mutants). Item 7, the live check on the fresh test host,
is the orchestrator's after the merge. Tests use a scratch HOME — never
the real `~/.claude`. Tests that read local times set `TZ`.

Review: stage 1 Opus, stage 2 Fable (privacy: which sessions are recorded;
writes under `~/.claude`).
