# WP-111 — Agent texts and docs for quiet drift (ADR-0028 WP-C)

Role: Engine Dev + Docs (Opus, high). Ships in 0.1.4. After WP-109 (and
WP-110 for the guide screenshots/wording). The skill's `drift.md` is in
WP-094, which starts after WP-101 and quotes ADR-0028 §3.

## Goal

Agents explain drift only with evidence; the session-start context lists
open crises and attention items; the docs say what is quiet and how to
opt in; a live check on the test host proves the Omakase promise.

## Inputs

decisions/ADR-0028-attention-by-consequence.md §3/§4c/§8 WP-C, ADR-0027,
engine/src/commands/hook/context.rs, the rules block and `seldon rules
update` (WP-100), docs/user/{en,de}/02, 03, 06, docs/CONCEPT.md "Drift
and Crisis", CHANGELOG.

## Outputs

Session-start context: crises and attention items of the last 7 days with
ids, quoted as data; rules block paragraph "drift: explain or link only
what your own Log, a hook event or the user's words prove" (block version
bump; `seldon rules update` path); guide 02/03/06 en/de (de stamps);
CONCEPT.md; CHANGELOG (series change, label skew of older plugins).

## Acceptance

`just check` 0; the orchestrator runs the live check on the test host
after the merge of WP-109/110/111: theme switch → nothing; plugin toggle
→ nothing (incl. `shell.json`); an update with a kernel → no crisis, one
release marker; terminal install of a package → quiet attention; a new
file under `~/.config/omarchy/hooks/post-update.d/` → red strip; enabling
a packaged user unit → nothing. Review: stage 1 Opus; stage 2 Fable for
the agent-facing text.

## Omarchy first (operator, 2026-10-06)

The agent texts name Omarchy's own commands where one exists (`omarchy pkg
add`, `omarchy hook install`, `omarchy theme set`, `omarchy refresh`) as
`$OMARCHY_PATH/default/agents/skills/omarchy/SKILL.md` does, and never
contradict that skill: Seldon's rules add the record, not a second way to
do Omarchy's work.
