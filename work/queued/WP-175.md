# WP-175 — The last slow paths: git's HEAD, a sparse ledger in the fast rebuild, a FIFO logbook.toml

0.2.x. Follow-ups from the reviews of WP-174 (Opus F7, Fable S1/S2,
2026-10-09). None hangs forever after WP-174; each is slow or unclear.

Role: Engine Dev. Small. Reviewer: Opus; Fable short (engine core).

1. **F7 — `.git/HEAD` as a FIFO** stalls each `git` child until the
   engine's 10 s git timeout: `status` ~40 s, `doctor` ~30 s. Check
   `.git/HEAD` (and `.git` itself) with `sys::open_regular`'s rule before
   the first `git` call of a command; refuse with what to do, once, and
   skip the remaining git calls of that command.
2. **S1 — `index::ledger_lines_exceed`** (`engine/src/index/mod.rs`) is
   type-bounded but not size-bounded: a huge sparse regular month without
   a newline stalls the hook's fast rebuild for minutes. Skip when the
   file is larger than `LEDGER_MONTH_MAX` (the normal read refuses it
   anyway).
3. **S2 — a FIFO at `.seldon/logbook.toml`** exits 3 "run seldon init"
   via `is_initialised`'s `is_file()`; no hang, but the message is wrong.
   Name the file and that it is not a regular file (exit 1, as WP-174).

**Acceptance.** Tests with a time limit for each; `just check` green.
