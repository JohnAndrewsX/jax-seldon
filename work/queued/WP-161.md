# WP-161 — Plugin harnesses never write into the real runtime dir

Ships in 0.1.4 (main) and 0.2.0 (next). Operator decisions 2026-10-08
E25 and E29. Highest priority: no plugin-test gate runs on the dev host
until this is merged.

Role: Engine Dev / Test infrastructure (Opus, high). Small.

**Incident.** On 2026-10-08 the dev host's Hyprland died with SIGBUS
(08:08) after `/run/user/1000` (tmpfs, 3.2 GB) filled up. The plugin view
harnesses set `XDG_RUNTIME_DIR="${XDG_RUNTIME_DIR:-$work}"`. In a desktop
session the variable is always set, and it is expanded before `env -i`,
so every test quickshell wrote `quickshell/by-id/<id>/` (logs) into the
real runtime dir. Quickshell never removes those folders, even on a clean
exit. About 34 700 runs in three days filled it.

**Do.**
- Every harness that starts quickshell uses its own runtime dir:
  `work=$(mktemp -d)`, `chmod 700 "$work"`, `XDG_RUNTIME_DIR="$work"`
  (or a short subdir of it; mind the socket path limit), removed by the
  existing trap. `bar-view.sh` already does this; fix `desk-view.sh`
  (next), `overlay-view.sh` and `panel-view.sh` (main and next), and any
  other quickshell start in `tests/` or `scripts/` that is not meant to
  reach the user's live shell.
- `scripts/deploy-test-host.sh:183` talks to the test host's live shell:
  keep it, and say so in a comment.
- A guard test fails when `XDG_RUNTIME_DIR:-` appears under `tests/`.
- `real-home-guard` (or the plugin-test recipe) records the number of
  entries in `/run/user/$UID/quickshell/by-id` before and after the
  plugin tests and fails if it grew.
- E29, less load: `just check` runs the plugin view harnesses only when
  `plugin/`, `tests/plugin/`, `schema/` or `fixtures/` changed against the
  merge base, unless `SELDON_FULL_CHECK=1` (gates set it). Document it in
  TESTING.
- Before a long run: `df -h /run/user/$UID` in the check's preamble, warn
  above 50 %, refuse above 80 %.

**Acceptance.**
- `just check` green with no entry added under the real
  `/run/user/$UID/quickshell/by-id` (show the counts before and after).
- The guard test fails on a mutant that brings back `XDG_RUNTIME_DIR:-`.
- Merged into main first, then main is merged into next and `desk-view.sh`
  gets the same fix there.
- CI green on the branch before the merge (shell scripts).
