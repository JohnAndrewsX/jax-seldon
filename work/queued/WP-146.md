# WP-146 — "Checked, nothing installed" as a recorded outcome

Ships in 0.2.x. Source: the study of the second predecessor "JARVIS" (private, in the orchestrator's notes; never in this repository). Operator decision 2026-10-07. (J4)

Role: Engine Dev with docs (Opus, medium). Small.

**Goal.** An evaluation that ends in "no" is part of the machine's memory.

**How.**
- A case tagged `evaluation` can be closed with the verdict
  `rejected` and a reason.
- Alternatively a decision with `status: rejected` names the software.
- `seldon recall <name> --json` (or a section of `memory`) lists earlier
  verdicts.
- The skill tells agents to search it before proposing software.
- The desk's Memory section shows the verdicts.

**Acceptance.**
- Tests: close as rejected, then recall finds it.
- The skill text.
- `just check` is green.
