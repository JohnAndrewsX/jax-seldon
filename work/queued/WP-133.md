# WP-133 — Guard: the Write and Edit tools by path

Role: Engine Dev (Opus, high). Operator decision 2026-10-07 (E3). Targets
`main` (the dev-host guard).

## Goal

The PreToolUse hook covers only the Bash tool. An agent can write under the
real `~/.config`, `~/Seldon` or `~/.local/state/seldon` with Write, Edit or
NotebookEdit. Add a path check for those tools: the AGENTS.md §6 red zone
blocks, the plugin dev install `~/.config/omarchy/plugins/jax.seldon` and
temp HOMEs pass.

## Inputs

`scripts/guard.sh` / `guard.py` (the path model: home, links, `..`),
the hook payload shape for Write/Edit (`tool_input.file_path`,
`notebook_path`), the hook config that installs the guard,
AGENTS.md §6, WP-130 TABLE.md.

## Outputs and acceptance

- The hook matcher includes Write|Edit|NotebookEdit; the path goes through
  the same resolution as a Bash write target (links made earlier do not
  apply; existing links are resolved).
- Table rows: writes into each red-zone path block (also via `..`, a
  symlink and `$HOME`-relative forms); the plugin dev install, the repo,
  the scratchpad and temp HOMEs pass.
- `just check-guard` and `just check` green; the operator sees the rows.
