# WP-024 — Logbook templates, logbook AGENTS.md, harness install, wizard first capture

## Goal
A fresh logbook explains itself to humans and agents in the chosen
language, the wizard finishes its job (first capture, hook install, theme
hook), and the optional Omarchy-Agent harness lands in the logbook when
the operator wants it.

## Inputs
docs/SPEC-ENGINE.md §3 §8 §9, docs/SPEC-LOGBOOK.md (all), decisions/ADR-0006
ADR-0007 ADR-0010 ADR-0011 ADR-0014 ADR-0017 ADR-0019, engine/templates/{en,de}/
(WP-003/006), engine/hooks/ (theme-set.sh, README), work/completed/WP-003/HANDOVER.md
(wizard steps, "first capture skipped"), work/completed/WP-005/HANDOVER.md
(theme hook install is the wizard's), work/completed/WP-009/HANDOVER.md
(`hook install claude-code`), work/completed/WP-013/FINDINGS.md §3 (stale
`init --json` capture text) and §2.2 (backfill opens with a red pill),
PROJECT.md (the Omarchy-Agent kit's zone model and guard stay where they are).

## Outputs
- Templates reviewed and completed in both languages: `AGENTS.md` for the
  logbook (rules for agents: engine is the only writer, `seldon log`,
  cases, zones, never edit the ledger; the hook commands), `PROJECT.md`,
  `DECISIONS.md`, areas, `memory/lessons.md`, `system/*.md`, case and
  decision bodies — English keys/headings, prose per language (ADR-0007).
- Wizard (`seldon init`): runs the first capture (`capture --all`, with an
  optional `--since` backfill step that explains the drift consequence and
  offers "mark the backfill as the pre-Seldon baseline" = one dismissal
  per item with reason "pre-Seldon baseline"); installs the Claude Code
  hooks when `--harness claude-code`; installs the theme hook via
  `omarchy hook install theme-set <file>` only on opt-in (the command is
  red-zone on the dev host: the wizard runs it, tests stub it); fixes the
  stale `init --json` capture text; `--non-interactive` defaults
  documented.
- Optional Omarchy-Agent harness: `--harness omarchy-agent` copies
  guard/skills from a template dir if present (document the path), else
  says what it would do.
- `docs/` for the orchestrator: a list of SPEC-ENGINE §9 edits in the
  handover.

## Acceptance tests
- `just check` exit 0; `seldon init --language de --non-interactive --path
  <tmp>` yields German prose templates with English keys; the English
  variant likewise.
- `init` runs the first capture (stub collectors in tests; the real-host
  run documented in docs/TESTING.md with scratch XDG dirs); `--since`
  backfill with baseline dismissal produces zero open drift afterwards.
- `--harness claude-code` writes `.claude/settings.json` (WP-009's
  installer, idempotent); the theme hook install is called exactly once on
  opt-in (stubbed `omarchy` records argv).
- Round-trip tests of WP-003 stay green.

## Constraints
Allowed crates only; red-zone commands only through stubs in tests; the
wizard never touches the operator's real logbook in tests (common::Env).
