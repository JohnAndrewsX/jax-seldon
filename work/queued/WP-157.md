# WP-157 — Redaction: the accidental paths left after WP-140

Ships in 0.2.x. The source is the Fable stage 2 of WP-140 (2026-10-08).
None of these is a blocker for the 0.2.0 tag.

Role: Engine Dev (Opus, high). Small.

**Items.**
- **Base64-wrapped PEM**, as in Kubernetes secrets and
  `"tls.key": "LS0tLS1CRUdJTi…"`: a rule
  `LS0tLS1CRUdJTi[A-Za-z0-9+/=]{40,}` masks the whole token.
- **Python single-quoted dicts:** `{'x-api-key': 'k'}`,
  `{'Authorization': 'Bearer …'}`.
- **More programs** with a secret on a privileged line:
  - `ssh-keygen -N/-P`;
  - `mkpasswd` (positional);
  - `mount -o pass=|pwd=|password=`;
  - `--password-file <(echo PW)` for programs that are not listed.
- **xargs:** `… | sudo xargs <prog>` is recorded whole today. Open `xargs`
  as a wrapper in the hook's parser.
- **Over-masking to tighten:**
  - `passwd -S alice | grep` today becomes `passwd ‹redacted›`; only a
    pipe *into* the program should count as fed;
  - `nmcli -g wifi-sec.psk con show` masks the word `con`.

**Acceptance.**
- A test row for each item, positive and negative.
- One mutant per rule.
- Linear time.
- `just check` and `just check-perf` are green.
