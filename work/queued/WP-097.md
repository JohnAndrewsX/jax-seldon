# WP-097 — Redaction: remaining credential forms on command lines

Role: Engine Dev (Opus, high). 0.1.4 follow-up, after WP-093 (same file,
engine/src/redact.rs, serial). From the WP-087 review (stage 2). Public
wording neutral.

## Goal

Credential forms that the command-line rules do not mask yet are masked,
in this priority:

1. A command continued over lines with `\` + newline, and quoted strings
   that span lines (multi-line `curl` is common in scripts). First confirm
   in the hook path that the full multi-line command text reaches
   redaction, and say so in the handover.
2. `--oauth2-bearer`, `--pass`, `-E` / `--cert file:password` (unique
   option names, cheap rules).
3. `http -a` / `xh -a` user:password.
4. `2>&1` before the credential option (usually last; lowest priority).

Not doing (document as limits in SPEC §7): the last `sshpass -p` of
several, `.netrc` contents echoed, abbreviated long options (`--us`).
