# WP-189 — Graph: the 0.3 layouts and the whole-logbook export

0.3 (operator decision E49: the Timeline preset is 0.3, not 0.2.x). From
the prototype 0.3 debate (`jax-seldon-private/prototype-0.3/debate-2026-10-09/`,
SYNTHESIS.md §3 NEW-WP-163b; items A12's 0.3 part, D-open-2); operator
decisions E31 (graph config panel; the export is 0.3 with an ADR), E49.

Role: Engine + Plugin Dev (Opus, high). Medium engine, medium plugin.
Reviewer: Opus; Fable stage 2 (a new `--json` command is contract, E42).
ADR: "Graph export" (the plan named in WP-163; Fable writes, next free
ADR number; the operator accepts).

**Problem.** The index is a window, not history: a time layout built on
it shows only the last N changes. Events carry no `area`, so lanes by area
collapse into one. The Prime Radiant already has a "Timeline" (SPEC
§6), so the name collides.

**Do.**
- **ADR:** `seldon graph --json` over the whole logbook with an
  engine-side layout (no tick in the shell); its output schema and
  CONTRACT row; how area reaches an event (or lanes by case); bounds
  (node cap, size) and the 400-node cap of ADR-0034 §5 for what the desk
  draws.
- **Engine:** the command, bounded and idempotent, with fixtures.
- **Plugin (Graph section, after WP-163's panel):**
  - the time layout, named "Lanes by area" (not "Timeline"), header "the
    last N changes, from <date>" when it falls back to the index window;
    cases or areas as lanes, unlinked events in one "no case" band;
  - the radial layout; computed once, never ticks;
  - diff (two dates) and the "This week" highlight;
  - colour groups (ordered rules filter → colour) through
    `Color.pick("seldon.<key>", <role>)` with one SPEC §7 line (C3); never
    read `colors.toml`;
  - crash nodes (WP-185) and the recipe overlay (E10) when those land.

**Acceptance.** The export run twice gives the same bytes; the schema
validates; the desk's timing gate at 400 nodes unchanged; harness cases
per layout; a theme sweep in 3 themes; `just check` green (private HOME
and XDG_RUNTIME_DIR).
