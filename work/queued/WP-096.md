# WP-096 — Default actor for launched agents

Role: Engine Dev (Opus, high). After 0.1.4; independent of WP-094/095
(may run in parallel, different files). No contract change: `actor`
already allows `agent:[a-z0-9-]+` (schema/event.schema.json $defs.actor).
Advisor scoping 2026-10-05 ("WP-C").

## Goal

A write by an agent that Seldon launched is recorded as that agent even
when it forgets `--actor`: today `seldon plan new/done` or `seldon log`
without `--actor` records as `human`.

## Inputs

engine/src/commands/agent.rs (launch), plan.rs, log.rs, drift.rs,
decide.rs, event.rs (`--actor` handling), schema/event.schema.json
(actor pattern), docs/SPEC-ENGINE.md §8, ADR-0023 (who closes).

## Outputs

- `seldon agent start` (and WP-095's `agent ask`, if merged first) sets
  `SELDON_ACTOR=agent:<launcher-name>` in the launched process, the name
  normalised to the schema pattern (refuse or map anything else; tests).
- `plan`, `log`, `drift`, `decide`, `event` use `SELDON_ACTOR` when
  `--actor` is absent; an explicit `--actor` wins; an invalid value is
  exit 1 with the allowed form.
- `plan done` (closing) by an agent actor: keep ADR-0023 advisory (record,
  do not refuse); say in the handover what the panel shows.
- SPEC-ENGINE §8, guide 04/05 en/de, CHANGELOG.

## Acceptance

`just check` 0; tests for env default, explicit override, invalid value,
launch sets the variable; mutants. Review: stage 1 Opus.
