# WP-172 — First-run findings: the tour's example, the pill count, Seldon's own plugin

0.2.0. From the fresh-host test T1 of 0.1.4 (orchestrator, 2026-10-09,
a freshly installed Omarchy 4.0.4, README path word for word).

Role: Docs Dev + Engine Dev. Small. Reviewer: Opus; the engine part
also Fable (class rules are engine core).

**Findings.**

1. **The tour's example is not drift.** README "A 60-second tour" and
   `docs/user/{en,de}/01-getting-started.md` use a theme switch as the
   example drift. Since the routine defaults (`theme` in the routine
   list) a theme switch is routine: `seldon capture` records it,
   `seldon drift` does not list it ("0 open drift item(s)"; only
   `drift --all` shows it as `routine`). The tour's `drift explain`
   step has nothing to explain.
2. **The pill does not show `· 1`.** The same texts say the pill shows
   `· 1` after the mark. The default `driftInBar` is `crisis`
   (`plugin/Model.js`), so a yellow drift item shows no count in the
   bar; the panel's Today says "1 without a case".
3. **Seldon's own plugin is the first drift.** README order is engine,
   `seldon init`, then `omarchy plugin add …jax-seldon-plugin… --enable`.
   The next capture records `plugin-add jax.seldon` as yellow drift
   (and the `shell.json` change as routine), so the first thing a new
   user is asked to explain is installing Seldon.

**Do.**

- (3) Engine: a `plugin-add`/`plugin-enable` of `jax.seldon` itself is
  routine under its own rule id (e.g. `seldon-self`), listed in
  `seldon doctor`'s drift line like the others; tests for add, enable,
  and that another plugin's add stays drift. SPEC-ENGINE §4 rule table.
  If this needs an ADR amendment of ADR-0028, write it (proposed).
- (1) Docs: pick a tour example that is drift by default and quick to
  undo, check it on a fresh logbook (`fixtures` or a temp HOME), and
  rewrite both language versions and the README tour with the real
  output. The case part of the tour (plan, log, link, verify, done)
  worked as written in T1 — keep it, with an event that is drift.
- (2) Docs: say what the pill shows by default (crisis count) and where
  the drift count is (panel Today; the `driftInBar` setting `all`).
- CHANGELOG.

**Acceptance.** On a fresh temp HOME with the defaults: the documented
tour runs command for command and prints what the docs show; installing
the plugin leaves `seldon drift` at 0; `just check` green.
