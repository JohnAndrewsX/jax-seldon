# WP-147 — What runs outside pacman

Ships in 0.2.x. Source: the study of the second predecessor "JARVIS" (private, in the orchestrator's notes; never in this repository). Operator decision 2026-10-07. (J5)

Role: Engine Dev (Opus, high).

**Goal.** The record matches the machine, also for software pacman does
not know:
- user binaries in `~/.local/bin`;
- AppImages and tarball installs under `~/.local` and `~/Applications`;
- user fonts in `~/.local/share/fonts`;
- the names of the MCP servers and skills each installed agent has.
  Names only, from the agents' config; never tokens or arguments.

**How.**
- Dossier facts (`system/*.md`) and a REBUILD.md section "outside pacman".
- Hashes or names only.
- Redaction of every path.
- The recipes (0.3) take it as input.

**Acceptance.**
- Fixture homes, idempotent.
- No secret from an MCP config reaches the dossier (test with a token in
  the args).
- `just check` is green.
