# WP-121 — The desk shell: window, width, sidebar, header, keys, settings, harness

Ships in 0.2.0 on the integration branch `next` (branch from and merge into `next`). Plan: decisions/ADR-0034-desk.md and the 0.2.0 plan (orchestrator's private notes); the prototype is the spec of look and behaviour (path in the brief).


Role: Plugin Dev (Opus, high). Wave 1, parallel to WP-120.

**Goal.** `Desk.qml` opens from the pill and from `shell toggle
jax.seldon` as a layer-shell window of the configured width on the
focused monitor, with header, KPI strip, sidebar, an empty list/detail
frame per section, the keyboard map and the Settings section; the old
popup and overlay are gone, the IPC shim is in place, and the new
harness drives it.

**Inputs.** ADR-0034 §1–§3, §7, §8; the prototype (`refs/ui-2026-10-06/
prototype-desk-v6.html`, private; layout, sizes, states, copy — in
English for the UI); LAGEBILD `ui/Panel.qml`, `ui/Lagebild.qml`,
`ui/Navigation.qml` (private; the three-pane build, collapse, digits,
Esc order); `$OMARCHY_PATH/shell/shell.qml` (panel loader, injection
order, `_updateSettings`/`updateEntryInline`, `Hyprland.focusedMonitor`
in `plugins/bar/Bar.qml`); `shell/Ui/*` and `Commons/Style.qml`,
`Color.qml`; `plugin/{BarWidget,Panel,Overlay,Service}.qml`,
`components/overlay/OverlayWindow.qml`; `tests/plugin/{panel-view,
overlay-view}.sh`, `harness/{panel,overlay}.qml`; SPEC-PLUGIN §1, §5, §6,
§8; AGENTS.md §7 plugin rules.

**Outputs.**
- `Desk.qml` (entry point; `open(payload)`, `close()`, `opened`,
  `section(id)`, `select(id)`, `view()`), `components/desk/{DeskWindow,
  Header, KpiStrip, Sidebar, ListColumn, DetailPane, ActionBar,
  Search}.qml`, `sections/Settings.qml` (Appearance live: slider,
  presets, preview; Capture/Agents/Quiet read-only with the pointer to
  where they are set); `sections/*.qml` stubs for 1–8 that render the
  section title and "coming in WP-12x" so the shell is testable.
- Width: the clamp of ADR-0034 §1; screen choice; centred below 100 %;
  sidebar auto-collapse under 960; stacked layout under 760.
- Settings keys `deskWidth`, `deskSidebar` in `manifest.json`
  (`defaults`, `schema`); `BarWidget.pushSettings` passes them to the
  service; the facade write with all keys, on release only; the fallback
  sentence when refused.
- Keyboard: digits, `,`, `Alt+↑/↓`, `/`, `Esc` order, `c`, `n`, `+`,
  `e` routed to the current section's `textKey`; the arm-twice helper
  shared by the sections.
- Pill: left click toggles the desk, middle click section 7; the
  `jax.seldon.panel` shim; `Panel.qml`, `Overlay.qml`, `OverlayWindow`,
  `OverlayHeader`, `Tabs.qml` removed (the chart components stay for
  WP-123).
- Harness: `tests/plugin/desk-view.sh` + `harness/desk.qml` with the old
  vocabulary and `section:`, `select:`, `width:`, `resize:`; the
  layer-shell stand-in; `HARNESS_SETTINGS` with the new keys; the two
  old scripts deleted with a `COVERAGE.md` beside the new one that lists
  every old scenario and its successor WP (122–125) or reason; `justfile`
  `plugin-test` updated; `model.test.js` keeps passing.
- SPEC-PLUGIN §1, §2, §5 (new), §6 (points to §5's section 7), §8
  rewritten for the shell; KEYBINDINGS.md.

**Acceptance.** `omarchy plugin validate plugin/` and `just qmllint` 0
warnings; `just check` 0; harness: opens at 50/67/75/100 % on 1366, 1920,
2560, 3840 px windows with the expected width and centring, sidebar
collapse and stack thresholds, digits and `Alt+↑/↓` wrap over nine
targets, `/` focuses search and Esc leaves it before closing, `,` opens
Settings, a slider release records exactly one settings write carrying
all keys, the shim's `tab work` lands on section 3, `toggle` twice
closes, log free of warnings and binding loops. Smoke test in a live
shell on the dev host with `SELDON_INDEX` (read-only dev mode). Review:
stage 1 Opus, stage 2 Fable (unsandboxed plugin, the first `shell.json`
write).
