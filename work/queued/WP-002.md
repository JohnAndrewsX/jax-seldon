# WP-002 — Contract and fixtures

## Goal
Freeze contract v1 and give both tracks realistic fixtures.

## Inputs
docs/CONTRACT.md, schema/*.json, fixtures/index.sample.json (draft shipped with the kit), docs/SPEC-LOGBOOK.md.

## Outputs
- Reviewed `schema/*.json` (fix anything the specs contradict; ADR if semantics change).
- `fixtures/logbook/` — a complete small logbook per SPEC-LOGBOOK: PROJECT.md, AGENTS.md, 3 cases (one per folder), 10 journal days, `ledger/2026-09.jsonl`, `ledger/2026-10.jsonl` (≈60 events incl. the three drift cases from the sample), decisions, dossier with fenced sections, memory.
- `fixtures/logs/pacman.log` (incl. transaction blocks, a rotation, malformed lines), `fixtures/logs/snapper.json`, `fixtures/logs/plugin-list-{before,after}.json`.
- `fixtures/hooks/claude-code-*.json` (mutating, non-mutating, secret-bearing).
- `scripts/validate-fixtures.sh` (jsonschema CLI or a tiny Rust test) wired into `just check`.

## Acceptance tests
- Every JSON fixture validates against its schema.
- `fixtures/index.sample.json` renders every plugin surface (Plugin Dev confirms in WP-010).
- The sample index is reproducible from `fixtures/logbook/` once WP-007 lands (golden test owner: this WP; test lands in WP-007).

## Constraints
Fixture prose may be German (it is user content). Keys, enums, paths English.

## Known issues in the draft fixture (found 2026-10-01)
- `fixtures/index.sample.json` events older than 2026-10-01 are generated
  filler with mismatched source/kind/subject (e.g. `pacman upgrade` of
  `110`, `snapper snapshot` of `~/.config/hypr/monitors.conf`,
  `config config-change` of `linux`). Replace them with events derived
  from `fixtures/logbook/ledger/*.jsonl` so the WP-007 golden test can hold.
- The drift rows and the cases are consistent and should be kept.
