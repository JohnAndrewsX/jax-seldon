# WP-113 — Code the collectors cannot see today (ADR-0028 WP-E)

Role: Engine Dev (Opus). Later; scope decision by the operator first —
each line item is approved separately (capture cost, privacy).

## Goal

Close the persistence gaps ADR-0028 names outside its core: third-party
plugin tree hashing (one `plugin-update` on a tree-hash change; hashes
only); the toggles state directory
`~/.local/state/omarchy/toggles/hypr/*.lua`; `~/.ssh/authorized_keys` as
an opt-in `alwaysRedPaths` example.

## Inputs

decisions/ADR-0028-attention-by-consequence.md §6, §8 WP-E;
engine/src/collectors/{plugins.rs,config.rs}; SPEC-LOGBOOK §7.

## Acceptance

Capture-cost numbers per item (`just check-perf`); idempotency tests; no
file content leaves the machine; review stage 1 Opus, stage 2 Fable.

## Added 2026-10-06 (WP-109 stage 1)

Pre-existing blind spots that yield zero events on hook paths: a hook
directory that is a symlink, a script with a NUL byte after line 1
(read as binary), a script over 1 MiB (skipped). Each one must yield an
event on a persistence path (hash only), so ADR-0028's crisis rows fire.

## Added 2026-10-06 (WP-109 stage 2)

- `system-link` (ADR-0028 row): hooks run `bash <target>` and
  `uwsm/env` is sourced, so a symlink to any root-owned script under
  `/usr/` runs at hook or login time. Narrow the mark: `systemd/user/**`
  only to `/usr/lib/systemd/user/`, `autostart/**` only to
  `/usr/share/applications/`, no mark elsewhere (a row change: ADR
  amendment by the orchestrator first).
- A file present when a path first becomes watched yields no event
  (`rescope`); a later rename to a loaded name shows only as a quiet
  `config-remove`. Consider a baseline hash list for persistence paths.
- yay/paru value options the parser does not know (`--answerdiff`,
  `--mflags`, `--editor` …) make their value a target, so such a full
  upgrade is attention `other`; extend `LONG_WITH_ARG`.
