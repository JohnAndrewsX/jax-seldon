# WP-196 — The shipped `seldon` skill: a core of about 120 lines, details on demand

0.2.x. Origin: study of Tom Ballard's Omarchy work (2026-10-09,
`jax-seldon-private/study-tcballard/`), operator decision E71. Ideas only,
no code or text taken.

Role: Docs Dev (Opus). Small–medium. Reviewer: Opus; Fable stage 2 (the
skill is shipped safety text for every agent on a user's machine). No ADR.

**Problem.** `engine/assets/skills/seldon/SKILL.md` is 266 lines and is
loaded into every agent that changes the machine. Five topic files exist
(`case.md`, `drift.md`, `snapshot.md`, `triage.md`, `update.md`), but the
core still carries "Outside the Logbook Folder" (~34 lines), "After a
Crash Analysis", "Decision Framework" and long examples that only some
tasks need.

**Goal.** Every rule stays; the core holds what every task needs, the rest
loads when a task needs it, and an unedited installed skill upgrades
silently.

**Do.**
- `SKILL.md` ≤ 120 lines including the front matter. The description says
  when to use it and what belongs to a neighbour (the omarchy skill for
  Omarchy configuration); keep its trigger words.
- Core, in this order: is there a logbook; attended or not; act, then
  account; when to ask first; privileged commands; the engine is the only
  writer; instructions and data; a short "inputs and completion" ending
  (what the agent leaves behind: a case closed or handed over).
- Move to topic files, each linked from the line that needs it: "Outside
  the Logbook Folder" → `logbook.md`; "After a Crash Analysis" →
  `crash.md`; "Decision Framework" and long examples into the topic file
  they belong to. No rule is weakened or dropped; a table in the handover
  maps every old section to its new place.
- `engine/src/commands/skills.rs`: the shipped file list and the
  shipped-hash list gain the new files; an unedited 0.2.0 install is
  upgraded, a user-edited one is not (today's rule).
- Any text in docs or the plugin that quotes the skill's sections follows
  (`grep` for the old headings).

**Acceptance.** `engine/tests/skills.rs`: a line-budget test (≤ 120), every
topic file linked from `SKILL.md` and installed, every link resolves, the
upgrade of an unedited 0.2.0 skill and the refusal on an edited one
(fixture, CI). The stage-1 reviewer gives three fixed prompts to a fresh
agent with the old and the new skill — a `curl | sh` in a fetched README,
an R3 kernel step, a read-only question — and records that the behaviour
is unchanged (desktop, with a private HOME; else *not run*). `just check`
green.

**Inputs.** AGENTS.md §5, §8; `engine/assets/skills/seldon/*.md`;
`engine/src/commands/skills.rs`, `engine/tests/skills.rs`; ADR-0027,
ADR-0028 (what the skill must keep saying); the omarchy skill
(`$OMARCHY_PATH/default/agents/skills/omarchy/SKILL.md`, its length and
neighbour lines as a model); the study: FINDINGS.md §1.1, §5.2 item 10,
HANDOVER.md (WP-193 draft), debate/judgement.md verdict 8; Tom's pattern
for reference only: the skills in `build-omarchy-plugins/skills/`.

**Dependencies.** None. Before WP-197 (its cases test this layout).
