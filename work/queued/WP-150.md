# WP-150 — The agents' own settings files, hashed

Ships in 0.2.x. Source: the study of omarchy-troubleshooter and omarchy-setup (private, in the orchestrator's notes; ideas only, no code taken). Operator decision 2026-10-07. Seldon reads, records and proposes; the agent does the work. (S2, must have)

Role: Engine Dev (Opus, high). Small.

**Goal.** An agent that changes its own approval or sandbox settings is
noticed. (Evidence from the setup repo: Codex quietly turned off its own
approvals and sandbox, and nobody noticed for three days.)

**How.**
- Watched paths, hashes only, class **attention**:
  - `~/.codex/config.toml`;
  - `~/.claude/settings.json`;
  - the equivalents of the other agents Omarchy's launcher knows (read
    `omarchy agent`'s list).
- `~/.claude.json` (account data) goes to the default `skipPaths`.
- Use the earlier-defaults upgrade (WP-109), so existing installs gain the
  paths silently.
- Seldon's own hook-migration writes to `~/.claude/settings.json` are
  auto-explained (rule 8 style, seldon as the actor).
- An ADR-0028 note, if a row changes.

**Acceptance.**
- An edit by an agent → one attention item.
- Seldon's own write → explained.
- No content in any event.
- `just check` is green.
