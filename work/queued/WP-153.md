# WP-153 — Locally changed and copied plugins as dossier facts

Ships in 0.2.x. Source: the study of omarchy-troubleshooter and omarchy-setup (private, in the orchestrator's notes; ideas only, no code taken). Operator decision 2026-10-07. Seldon reads, records and proposes; the agent does the work. (S5, nice to have)

Role: Engine Dev (Opus, medium).

**Goal.** An update that will overwrite a local patch is named before it
happens.

**How.**
- Per git-installed third-party plugin, two facts:
  - "local changes: N files" (`git status --porcelain`, read-only, with
    WP-136's hardening);
  - "HEAD differs from the commit last recorded".
- A case can record which first-party plugin a copy is based on, for the
  recipes in 0.3.

**Dependencies.** WP-136.

**Acceptance.**
- A fixture clone with a local edit → the fact.
- The hardening tests from WP-136 apply.
- `just check` is green.
