# WP-045 — User documentation in English and German (docs/user/<lang>/), multilingual layout

## Goal
A user who has never seen Seldon installs it, understands the ideas, works
with the panel, the Prime Radiant, the CLI and their agents, and finds
help when something is off — in English (source of truth) or German
(complete translation). The layout is ready for more languages.
Operator decision 2026-10-02: English primary, German now; further
languages later when there is demand (tracked in docs/VERSIONING.md or
a ROADMAP line).

## Inputs
README.md (after WP-046 is queued; the install text from WP-044),
docs/CONCEPT.md, docs/SPEC-ENGINE.md §2 §3 §5 §7 §8 §9, docs/SPEC-LOGBOOK.md,
docs/SPEC-PLUGIN.md §3 §5 §6 §8, docs/KEYBINDINGS.md, docs/AGENT-GUIDE.md
(WP-047), work/PHASE-0-EXIT.md and the transcript, work/completed/
WP-043/HANDOVER.md (import), engine `--help` texts (generate the CLI
reference from them and keep a check that they match), plugin/README.md,
the renders under work/completed/WP-03*/screenshots and plugin/preview.png.

## Outputs
- `docs/user/en/` and `docs/user/de/` with the same file set and a
  `README.md` index per language; the root `docs/user/README.md` links
  both and states the translation policy (English is the source; a
  German page carries the source commit it matches).
  Pages: 01-getting-started, 02-concepts (logbook, cases, zones, risk,
  drift, baseline, crisis, decisions, memory), 03-daily-use (pill, panel
  tabs, keys, Prime Radiant, periods), 04-working-with-agents (Claude
  Code, Omarchy Agent, hooks, active case, `agent start`),
  05-cli-reference (every command and flag, generated from `--help`,
  grouped), 06-configuration (`config.toml` reference, collectors,
  watched paths, redaction, agent launcher), 07-the-logbook (folders,
  files, what the engine owns, what you own, Obsidian setup), 08-rebuild
  -dossier-update-impact, 09-import-from-omarchy-agent, 10-troubleshooting
  (`doctor`, degraded states, lock, stale index), 11-update-and-uninstall,
  12-faq, 13-glossary (en/de term table).
- Screenshots reused from the repository (no new live shots needed);
  alt text in the page language.
- A `just docs-check` recipe: links resolve, both languages have the same
  page set, the CLI reference matches `seldon <cmd> --help` output
  (script in `scripts/`), wired into `just check`.
- CHANGELOG `[Unreleased]` line; README links to `docs/user/`.

## Acceptance tests
- `just check` exit 0 incl. `docs-check`.
- A reviewer follows 01-getting-started on the test host (or a scratch
  home on the dev host) top to bottom and succeeds.
- German pages are complete translations, not summaries (same headings,
  same examples; commands untranslated).

## Constraints
English public policy (AGENTS.md §2) applies to file names, identifiers
and commands; German prose only inside `docs/user/de/`. No engine or
plugin code. A guard block is reported, never worked around.
