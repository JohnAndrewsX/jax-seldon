# WP-163 — Graph config panel: filters, groups, display, forces, presets

Ships in 0.2.x on `next`. Operator decision 2026-10-08 (E31). **Start
only after the operator has reviewed the prototype** (the private 0.3
prototype shows the panel first; its FEEDBACK.md and the operator's notes
are inputs).

Role: Plugin Dev (Opus, high). Medium.

**Goal.** An Obsidian-like config panel for the Graph (section 8) with
presets the user picks and configs the user saves. Plugin only: no engine
or contract change.

**Do.**
- A collapsible panel at the graph's right with four groups:
  - Filters: search (title, id), node kinds, areas, sources, class
    (crisis, attention, routine), case status, actor (human, agent), a date
    range, "connected only";
  - Groups: ordered rules "filter → colour", colours from `Style`/`Color`
    tokens only;
  - Display: labels (always, zoomed, never), node size by (links, changes,
    fixed), edge width, arrows, layout (forces; time axis with a lane per
    area);
  - Forces: repulsion, link length, centre pull, spring strength, with a
    reset.
- Presets shipped: Overview, Crises & risk, Agent footprint, This week,
  Decisions map, Area focus, Timeline. A preset picker in the graph's
  header row, and a key.
- User configs: save as, rename, duplicate, delete, set as default; stored
  through Omarchy's plugin settings (Omarchy first; read
  `$OMARCHY_PATH/default/agents/skills/omarchy/plugins.md` and the
  settings pattern of the built-in plugins), never in the logbook.
- The local graph (1–2 hops) in a case's or event's detail, and "View in
  Graph" from a detail.
- The ADR-0034 §5 budget holds: filtering happens in `graphBuild`, the
  400-node cap and the 8 ms tick stay; a filter that leaves fewer nodes
  shows them unfolded.

**Inputs.** `jax-seldon-private/reports/2026-10-08-graph-ideen.md`
(private; data), the prototype's graph iteration and FEEDBACK.md, SPEC-PLUGIN
§5.4, ADR-0034 §5.

**Acceptance.** Harness cases per preset and per filter group; a saved
config survives a shell restart; the timing gate at 400 nodes is unchanged;
theme sweep; `just check` green (private runtime dir).

**Later, 0.3 (own ADR):** `seldon graph --json` over the whole logbook
with an engine-side layout, crash nodes (E28), the recipe overlay (E10).
