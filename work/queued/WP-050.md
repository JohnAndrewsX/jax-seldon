# WP-050 — Advisory risk warnings, alwaysRed alignment, stale concept/spec lines (ADR-0023 follow-ups)

## Goal
The engine advises on risk the way ADR-0023 describes, the default red
list matches the R3 subjects, and two stale documentation lines found by
the WP-047 review are fixed.

## Inputs
decisions/ADR-0023, docs/SPEC-LOGBOOK.md §3 (risk levels), docs/SPEC-ENGINE.md
§2 (`[drift] alwaysRed`) §3 (`plan start --snapshot`, `hook install`),
engine/src/commands/plan.rs, engine/src/config.rs (alwaysRed default),
engine/src/commands/hook.rs (install accepts only `claude-code`),
docs/CONCEPT.md ("Agents and the logbook" still names PostToolUse/Stop;
ADR-0017 and SPEC §8 say PreToolUse/SessionEnd), work/completed/WP-047/HANDOVER.md.

## Outputs
- `seldon plan start` on an R2 or R3 case without `--snapshot` prints a
  warning (and `warnings: [...]` in `--json`), never refuses; R3 adds
  "the human's explicit go per step" to the warning. Tests.
- The default `[drift] alwaysRed` list reviewed against the R3 subjects
  in ADR-0023 (kernel, systemd, glibc, Hyprland, Omarchy itself, boot
  loader, `/etc`); SPEC-ENGINE §2 lists the final default.
- docs/CONCEPT.md "Agents and the logbook" updated to PreToolUse/SessionEnd.
- SPEC-ENGINE §3: `hook install <claude-code|generic>` — either implement
  `generic` (writes the documented generic hook script) or drop it from
  the synopsis; say which in the handover (the binary accepts only
  `claude-code` today).
- CHANGELOG `[Unreleased]` lines.

## Acceptance tests
- `just check` exit 0; the warning tests; `seldon plan start --help` and
  the spec agree.

## Constraints
No new crates; never run against a real logbook; a guard block is
reported, never worked around.
