# WP-073 — collectors: plugins dedupe, capture-time attribution window, verb-aware plugin proofs, SELDON_NOW in capture, reused snapshot numbers

Role: Engine Dev (Opus, high). Size: L. Wave: 5. Depends: WP-069
(`tests/idempotency.rs`), WP-071 (`attribution.rs`,
`tests/attribution.rs`), WP-060 (`collectors/snapper.rs`,
`tests/collectors.rs`).
Findings: F-100 (plugins half; the config half is WP-069), F-105, F-106,
F-103, F-104.

## Goal

- **F-100 (plugins)** — plugins events are deduplicated against the
  ledger since `prev.checked` (collectors/plugins.rs ~188-197), so a
  failed cursor save does not repeat them.
- **F-105** — events stamped with the capture time (plugin and
  config removals, plugins.rs ~307-311, config.rs ~529-530) accept causes
  in `[prev.checked − window, now]` (attribution.rs ~42, ~126).
- **F-106** — `omarchy plugin <verb> <id>` proves only the matching event
  kind (add/remove/enable/disable/update) (attribution.rs ~170-177).
- **F-103** — `capture` uses `ctx.now` (nanos stripped), so `SELDON_NOW`
  applies (commands/capture.rs ~97-98).
- **F-104** — the snapper cursor stores each snapshot's date; a number
  seen with a different date emits `snapshot-delete` plus `snapshot`
  (snapper.rs ~166). Old cursors without dates: no events, dates filled.
