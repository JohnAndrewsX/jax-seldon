# WP-095 — Task prompts from the panel: ask an agent about a drift row or a case (revised for ADR-0027)

Role: Engine Dev + Plugin Dev (Opus, high). After WP-094 (the prompts
rely on the skill) and WP-101 (which owns the one-click "New case";
this WP no longer does). Needs its own ADR first: "agent prompts carry
identifiers, never logbook text" (covers `agent start`, `agent start
--new`, and the `ask` kinds). No contract change unless that ADR says
otherwise.

## Goal

One click on a drift row ("Ask agent") or on a case starts the default
agent with a task prompt that names only ids; the agent reads the text
itself through `seldon … --json` and — per ADR-0027 — resolves the drift
(`drift explain|link|dismiss` when the reason is known, else asks) or
continues the case, closing it when verified.

## Inputs

engine/src/commands/agent.rs (`prompt`, launcher, WP-101's `--new`),
config.rs `[agent] launcher`, plugin drift sheet (WP-021) and case rows,
AGENTS.md §8 (fixed argv), ADR-0027 §2 and §5, the WP-094 skill
(drift.md, case.md), docs/SPEC-ENGINE.md §8, SPEC-PLUGIN.md.

## Outputs

- ADR-NNNN "Agent prompts carry identifiers, never logbook text".
- `seldon agent ask drift <eventId>` and `seldon agent ask case <id>`
  (validated ids, `--json`, fixed prompt templates that point at the
  skill, `SELDON_ACTOR` and `SELDON_ATTENDED=1` set like `agent start`);
  `seldon agent ask update` once WP-033 exists.
- Plugin: "Ask agent" on the drift sheet and in the case view, fixed argv
  with a validated id, busy state, refusal when no default agent is set.
- Tests: id validation, prompt contains no logbook text (mutant),
  harness cases for both buttons; guide 04 en/de.

## Acceptance

`just check` 0; mutants; live check on the test host (drift row → agent
starts, resolves or asks). Review: stage 1 Opus, stage 2 Fable (prompt
injection, unsandboxed plugin).
