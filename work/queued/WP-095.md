# WP-095 — Task prompts from the panel: ask an agent about a drift row or a case

Role: Engine Dev + Plugin Dev (Opus, high). After WP-094 (the prompts
rely on the skill). Needs an ADR first: "agent prompts carry identifiers,
never logbook text". No contract change unless the ADR says otherwise.
Advisor scoping 2026-10-05 ("WP-B").

## Goal

One click on a drift row ("Ask agent") or on a case starts the default
agent with a task prompt that names only ids; the agent reads the text
itself through `seldon … --json` and proposes `drift explain|link|dismiss`
or the next case step.

## Inputs

engine/src/commands/agent.rs (`prompt`, launcher `omarchy agent prompt
{prompt}`, config.rs `[agent] launcher`), plugin drift sheet (WP-021) and
case rows, AGENTS.md §8 (fixed argv, never shell strings from logbook
content), ADR-0023, the WP-094 skill (drift.md, case.md),
docs/SPEC-ENGINE.md §8 and SPEC-PLUGIN.md.

## Outputs

- ADR-NNNN "Agent prompts carry identifiers, never logbook text"
  (covers `agent start` and the new kinds).
- `seldon agent ask drift <eventId>` and `seldon agent ask case <id>`
  (validated ids, `--json`, fixed prompt templates that point at the
  skill); `seldon agent ask update` once WP-033 exists.
- Plugin: "Ask agent" on the drift sheet and in the case view, fixed argv
  with a validated id, busy state, refusal when no default agent is set
  (the engine's message, `omarchy default agent` fix).
- Tests: id validation, prompt contains no logbook text (mutant),
  harness cases for both buttons; guide 04 en/de.

## Acceptance

`just check` 0; mutants; live check on the test host (drift row → agent
starts with the prompt). Review: stage 1 Opus, stage 2 Fable (prompt
injection, unsandboxed plugin).
