# WP-046 — README overhaul of both repositories to GitHub best practice; developer docs moved out

## Goal
The root README sells and explains Seldon to a newcomer in one screen,
gets them installed in two minutes, and routes everyone else (users,
agents, contributors) to the right document; the plugin README (the
`jax-seldon-plugin` repository's front page) matches it.

## Inputs
README.md, plugin/README.md, docs/user/ (WP-045), docs/AGENT-GUIDE.md and
llms.txt (WP-047), install.sh and the install text (WP-044), CONTRIBUTING.md
and SECURITY.md (WP-048), plugin/preview.png and docs/images/, CHANGELOG.md,
decisions/ADR-0009 (plugin split), the GitHub README best-practice
checklist (title + one-liner, badges, hero image, why, features, quick
start, docs, status, contributing, licence; read-only reference).

## Outputs
- Root `README.md`: badges (CI, release, licence), hero image (panel +
  Prime Radiant), one-paragraph pitch, "Why", features in six bullets,
  Quick start (plugin `omarchy plugin add …`, engine via AUR or
  `install.sh`, `seldon init`), a 60-second tour, documentation table
  (user docs en/de, agent guide, specs), project status and roadmap
  line, contributing, security, licence, acknowledgements.
- The current developer content moves to `docs/DEVELOPMENT.md` (reading
  order, layout, how the team works, links to ORCHESTRATION/PLAN).
- `plugin/README.md`: same skeleton adapted to the marketplace template
  (Install, Usage, Configure, Remove stay as section names), both engine
  install paths, pointer to the user docs and the agent guide; the split
  repository shows this file as its front page — check how relative
  links and images behave after `git subtree split` (links must be
  absolute to the monorepo where the target is not in `plugin/`).
- Both READMEs render cleanly on GitHub (tables, images, anchors);
  `README.md` has a table of contents only if longer than two screens.

## Acceptance tests
- `just check` exit 0 (link check from WP-045 covers the READMEs).
- A reviewer reads both READMEs as a newcomer and can install and start
  without opening another file; every link resolves on GitHub (public
  repo URLs).

## Constraints
English; no code changes; images ≤ 1 MB each; a guard block is reported,
never worked around.
