# WP-127 — the index carries what the desk's details show

Ships in 0.2.0 on the integration branch `next`: branch from `next` and
merge into `next`.
- Basis: ADR-0035 §6 as accepted. Before the 0.2.0 tag, an accepted ADR
  may add **optional** fields to the v2 schemas in the same contract
  version.
- Source: Fable's stage 2 of WP-120 (2026-10-07).

Role: Engine Dev (Opus, high), with a small plugin part.
Wave 3, after WP-120, WP-122 and WP-123 are on `next`.

**Goal.** The desk's details stop guessing and stop sending the user to
the editor for one-liners. Each change is optional and backwards
compatible, and adds about 25 KB at the index caps:

- `drift[].rule`: the ADR-0028 rule id that classified the item. The
  engine already computes it for `drift show`. Without this field,
  WP-122's "why loud" callout starts one process per selection.
- `cases[].intent` and `cases[].result`: the first paragraph of each,
  clipped to 256 characters as in ADR-0025.
- `decisions[].lead`: the decision's first paragraph, clipped the same
  way.
- `cases[].source`: for an imported case only, `~/…/file.md#line`,
  redacted. WP-102b's "imported from" line needs it. Decide whether the
  engine derives it from the import marker or writes it as an optional
  frontmatter key (WP-102 handover, contract question).

**Inputs.**
- ADR-0035 (§6, as accepted), ADR-0028 (rule ids), ADR-0025 (clipping),
  ADR-0034 §2.
- docs/CONTRACT.md rule 9.
- WP-122's Model.js `whyLoud` and its `drift show` call, and WP-123's
  decision and memory details, both as built on `next`.
- The Fable stage-2 note on WP-120 (orchestrator's private review notes).

**Outputs.**
- A short ADR (ADR-0038, proposed) that adds the four optional fields
  under ADR-0035 §6.
- schema/index.schema.json with the four optional fields and their
  maxima.
- The engine writes them; redaction applies to the text fields.
- Fixtures regenerated.
- `scripts/validate-fixtures.py`: the reference derive carries the new
  fields.
- Plugin:
  - `whyLoud` reads `rule` when present and falls back to the
    `drift show` call when it is absent.
  - The Work and Decisions details show intent, result and lead, with
    *Open in editor* staying.
- CONTRACT.md rule 9 extended.

**Acceptance.**
- `just check` is green.
- The sample renders every new field.
- An index without the fields still renders, which proves the fields are
  optional.
- The 0.1.x plugin case is unchanged.
- The redaction test covers the new text fields.
- No new process per click in the Changelog when `rule` is present.

**Dependencies.** WP-120 (contract v2) is merged into `next`. WP-122 and
WP-123 are merged into `next`. WP-102a is on `next` for `source`.
