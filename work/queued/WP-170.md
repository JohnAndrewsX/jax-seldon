# WP-170 — Boot-file changes: crisis unless the owner's update explains them

0.2.x/0.3; an ADR amending ADR-0028 §2 (from the WP-164 review). Waits
for the operator's feedback on live attention items.

Role: Advisor (ADR) + Engine Dev. Small.

**Proposal.** A change to a boot-configuration file (WP-164's list) is a
**crisis**, unless the same capture window holds a pacman transaction of
the package that owns it (`omarchy-settings`, `mkinitcpio`,
`limine-mkinitcpio-hook`, read from pacman.log) or an `omarchy` version
change (its migrations write e.g. `/etc/default/limine`); inside such a
window the change is **routine**, under its own rule id. Today (WP-164)
every boot-file change is attention.

**Do.** ADR (proposed), then the rule in `class.rs` with tests for both
sides of the window; SPEC, guide, CHANGELOG.
