# WP-056 — docs: uninstall with a kept logbook, state directory backup, watcher README

Role: Docs (Sonnet, medium). Size: S. Wave: 0. Depends: none.
Findings: F-454, F-458, F-450 (docs part only; the engine part waits for
an operator decision, see the plan).

## Goal

The user guide and the watcher README say what the engine actually does.

- **F-454** — `docs/user/{en,de}/11-update-and-uninstall.md` step 4: when
  the logbook is kept, `seldon hook uninstall claude-code` (no
  `--settings`) removes the logbook's own hooks; a global install also
  needs the `--settings` form. Without it, Claude Code keeps calling a
  missing `seldon`.
- **F-458** — `engine/systemd/README.md` step 1: the release binary and
  the AUR package already include `watch` (release.yml builds with
  `--features watch`); building with the feature is only for source
  builds and must not overwrite the installer-managed binary.
- **F-450 (docs)** — `docs/user/{en,de}/07-the-logbook.md`: a short
  section "Back up and restore the state directory": what lives in
  `~/.local/state/seldon/` (cursors.json, manifest.json, owned.json,
  index.json), that losing it makes the collectors start over silently
  (config, plugins, omarchy, theme changes made meanwhile are not
  recorded), and how to back it up and restore it.
