## From the Tom Ballard study (2026-10-09)

Source: `jax-seldon-private/study-tcballard/` (REPORT.md, FINDINGS.md,
HANDOVER.md "Amendments", debate/judgement.md); operator decisions E64–E75
(STATUS.md, all as recommended). Ideas only, no code taken.

- **Plain text over the whole plugin (E72):** a node test (e.g.
  `tests/plugin/plaintext.test.js`, run by `plugin-test` and in CI via
  WP-190) that every `Text {` in `plugin/**/*.qml` declares
  `textFormat: Text.PlainText`; an exception needs an allow-list line with
  its reason. Today every block declares a `textFormat` (study, 170
  occurrences), but only some files are tested
  (`tests/plugin/model.test.js`). A mutant proves the test (fixture, CI).
- **Index size limit (E72):** `plugin/Service.qml` checks the length of
  `index.json`'s text before `JSON.parse` against the contract's budget
  (CONTRACT.md rule 5, < 1 MB; the comment at `Service.qml:10-11` relies on
  it). Over the limit the plugin takes its existing parse-error path
  (`parsed.error`, `Model.bannerFor`) with its one-click fix and a message
  naming the size (no new state, no contract change); a case in
  `tests/plugin/service-states.sh` with a generated oversized index
  (headless) and in `model.test.js` if the check lives in `Model.js`.
- **Store README (E64):** WP-042's README changes (no `curl … | bash`
  fence, privilege wording in the scanner's form) are merged before this
  WP; the docs pass keeps them and `tests/release/store-readme.test.sh`
  stays green.
- **Highlights (E68):** write `### Highlights` for 0.2.0 (≤ 10 user bullets,
  Breaking included) with WP-193's mechanism; the release-notes draft for
  the operator's go is `packaging/release-notes.sh 0.2.0`'s output.
- **Recorded live test (E67):** the four live scenarios write
  `packaging/acceptance/v0.2.0.json` in WP-192's format (commit deployed,
  `omarchy version` and channel, counts per ADR-0027 §1, each `where` an
  AGENTS.md §5 evidence word); the tag question quotes
  `packaging/acceptance-check.sh 0.2.0` on the release commit. If WP-194
  has landed, its `--gate` runs on the test host first; otherwise the
  record lists it as `not run`.
- **Docs pass, two sentences:** SPEC-PLUGIN §9's "Quickshell 0.3.1 does not
  reload plugin code on file change" becomes the measured fact (a reload
  happens; new code needs a shell restart; `memory/omarchy-shell.md`);
