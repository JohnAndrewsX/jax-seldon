Role: QA + Docs (Opus, medium for docs chains, high for the live check).
Wave 4, after all of the above.

**Goal.** `next` is releasable: documentation matches the desk, the
plugin follows three themes, a fresh user and a 0.1.x user both arrive
at the desk without a question, and `main` has it.

**Inputs.** ADR-0034, ADR-0035, ADR-0036; WP-119 and WP-102 as built
on `next`; WP-113/114 collector docs; CHANGELOG; `docs/user/` guides
en/de; `plugin/README.md`, `SECURITY.md`, `preview.png`; KEYBINDINGS.md;
`docs/TESTING.md` plugin sections; `packaging/` release workflow and
VERSIONING.md; WP-098 (test host follows main); the 0.1.4 tag state.

**Outputs.**
- Docs: SPEC-PLUGIN final pass; guides 01–05 and 10–11 en/de (desk
  screenshots, keys, width setting, triage, graph, "what changed from
  0.1.x"); README states table (engine missing, logbook not initialised,
  index missing, index stale — each with its one-click fix in the header
  chip); TESTING.md §3 rewritten for `desk-view.sh`; `preview.png` and
  `docs/images/` from the test host.
- Theme sweep: Tokyo Night, Kanagawa, Catppuccin Latte shots at 50 % and
  100 % on the test host, checked by `check-tokens.py` (no hard-coded
  colours) and by eye.
- Live check on the test host (fresh Omarchy 2026-10-07): (a) clean home
  → plugin add → setup card → desk opens at 100 %, Today shows "Seldon is

  all nine targets by key; counts per ADR-0027 §1 in the handover.
- Versions: `0.2.0` in `Cargo.toml`, manifest, `Model.js`; `engineMin`
  0.2.0; CHANGELOG **Breaking** (popup and overlay replaced, keyboard
  map, IPC shim, contract 2) and **Added**; release notes draft.
- `next` → `main`: after the 0.1.4 tag exists, one merge PR, main checks
  green, test host back on `main`.

**Acceptance.** `just check` 0 on the merge commit; `omarchy plugin
validate` and qmllint 0; the four live scenarios pass with their counts
