# WP-179 — Equal safety in PRO: Needs you, the stopped update, Pick your agent

0.2.y (ADR amendment and a CONTRACT row, no `contractVersion` bump). From
the prototype 0.3 debate (`jax-seldon-private/prototype-0.3/debate-2026-10-09/`,
SYNTHESIS.md §3 NEW-4; items C5, C6, B2); operator decisions E50, E51,
E52, E59 (and E42 for the additive field).

Role: Engine + Plugin Dev (Opus, high). Small engine, medium plugin.
Reviewer: Opus; Fable stage 2 (safety, contract row). ADR: proposed by
this WP (Fable writes, next free ADR number): "ADR-0045 amendment: Pick
your agent, the stopped update, the cue bound, engine titles".

**Problem.** PRO's "Needs you" lists crises only and the headline says
"Nothing needs you" (`Model.js`, the Today sentence) while an interrupted
`pacman -Syu` may have skipped its boot hooks. ADR-0045 §6 sends the user
to `omarchy default agent`, which without a name only prints
(`$OMARCHY_PATH/bin/omarchy-default-agent`); the chooser is Omarchy's menu
route `setup.default.agent`.

**Do.**
- **ADR (proposed).** Amends ADR-0045 §5/§6: the menu route replaces the
  terminal line (E51); `error.reason` as the detection; the leave rule
  (E50); the PRO cue's opacity pulse ≤ 5 s per desk open, then still
  (E52); the engine titles EASY's "It was me." cases from kind and
  subject, "<kind> <subject>, explained by you" (E59). WP-187 builds the
  last two.
- **`Model.needs(index, service)` (B2)** over sources that exist: crises,
  the stopped update, the setup card (WP-119), "Pick your agent". Each row:
  glyph + word + actor, one main action. The Today sentence counts them;
  the group heading does not. Later kinds (WP-145, WP-149, crashes,
  reports) join in their own WP with a safety-equality test.
- **Stopped update (C5).** One row per stopped transaction (leader
  `txId`, `meta.txStatus`, ADR-0043) in PRO's Needs you: urgent stripe,
  "! update stopped · <status> · <who>"; the detail is the existing
  transaction detail; the headline counts it; never in the pill. **Leaves
  (E50)** when every package marked ↑/↻ in it appears in a later
  transaction without `txStatus` (what `TX_SAFE_STEP` asks), or when the
  transaction leaves the 500-event window. The Changelog keeps the mark.
- **Pick your agent (C6, E51).** Engine: the refusal in
  `engine/src/commands/agent.rs` (the "no default agent" check) adds an
  additive `error.reason: "no-default-agent"` to the `--json` error;
  CONTRACT.md row and fixture, no bump (E42). Plugin: the desk yields focus
  first, then runs the fixed argv `["omarchy-menu", "summon",
  "setup.default.agent"]` (Seldon writes nothing). Shown in place as the
  refused action's result line and as a Needs-you row for the session,
  cleared on the next success or desk open. `seldon doctor` reports a
  missing default agent.

**Acceptance.** Synthetic-event tests (`model.test.js`) for the row, the
leave rule (all marked packages reappear; only `pacman -S htop` follows →
row stays) and the window edge; the headline never says "Nothing needs
you" above a row; `bar-view.sh` pill unchanged; `error.reason` fixture
validates and engine test pins it; `doctor` row; on the test host the
menu opens with the desk closed (orchestrator live check); `just check`
green.
