## What was done

### Engine — `seldon preview [--days N] [--json]`

- `engine/src/commands/preview.rs`: read-only; no logbook needed (one that
  exists is not read), no lock, nothing written (no state directory, no
  config). Reads `config.toml` when present for `[redaction] skipPaths` and
  `patterns`; an unreadable config or invalid patterns withhold the file
  list (`files.ok: false`) and the pacman command lines.
- pacman: the tail of `pacman.log` in growing slices (256 KiB × 4ⁿ, cap
  64 MiB → `partial`), parsed by the collector's own `pacman::parse`;
  package lines in the window, grouped by transaction, newest first, with
  `at`, `command` (redacted, one line, ≤ 256 chars), `status` (ADR-0043),
  `count`, `kinds`, ≤ 10 `packages`.
- `engine/src/config_scan.rs` (neutral module, **meant for WP-139's
  capture-time list as well**): bounded mtime walk of `$XDG_CONFIG_HOME`;
  symlinks never followed, depth ≤ 16, ignore list (caches, `Cookies` /
  `Local State` profiles, state, logs, crash folders, databases, dconf,
  images, locks, swap/backup files, `.git`, `omarchy/plugins`,
  `omarchy/shell.json`), `skipPaths` honoured; newest-N with a total count;
  deadline and entry budget → `partial`.
- Bounds: ≤ 7 days, ≤ 200 rows (files first, ≤ 80), ≤ 10 packages listed
  per transaction, walk stops at 0.4 s; `truncated` when cut.
- `schema/preview.schema.json`; `fixtures/preview.sample.json` (the
  engine's own output for the test's fixture home and
  `fixtures/logs/pacman-preview.log`, held equal by
  `engine/tests/preview.rs`, `SELDON_WRITE_PREVIEW_SAMPLE=1` rewrites it);
  four `fixtures/invalid/preview.*.json`; `validate-fixtures.py` maps them
  (and its builtin validator learned `maximum`).

### Plugin

- `Model.validateArgs`: `preview --json`, nothing else.
- `Service.qml`: `previewCall`, its own read-only process beside the queue
  (like `doctor --only rules` and `agent sessions`); asked when the status
  becomes `notInitialised`, when the engine probe answers, and when the desk
  opens (if older than 5 min); never in dev mode; cleared when the status
  leaves `notInitialised`.
- `Model.previewResult` re-checks shape and bounds and drops unreadable
  rows; `previewRows` (PACKAGES · LAST 7 DAYS, EDITED CONFIG FILES — the
  header is upper-cased by `GroupedRow`, so no path in it), search over all
  listed package names; `previewSummary`.
- `sections/Today.qml`: while not initialised, the list shows the preview
  rows; the overview's `todaySetupSlot` holds the card *Before Seldon* —
  "This is without memory: no who, no why, gone when the logs rotate. Set
  up Seldon?" — the summary line and **Set up Seldon**, which is the
  notInitialised notice's terminal fix (init script; the desk steps aside).
  WP-119's setup card takes the slot over.

## How it was verified

- Engine unit tests (scan: window, ignore list, profiles, skipPaths,
  symlinks, bound, budgets, depth, missing root; preview: tail start, tail
  cap, window edge, Running-line time, redaction and bidi, bounds) and
  `engine/tests/preview.rs` (9 tests: golden sample + schema, nothing
  written before and after `init`, `--days` 1–7, missing log, unusable
  config withholds, user skipPaths and patterns, row bounds, a 32 MiB log
  with 5 000 files).
- `tests/plugin/model.test.js`: 6 new tests. `desk-view.sh`: `preview-uninit`
  (live fake engine, rows, card, Set up Seldon → init terminal argv
  recorded, the preview in its own process, never in argv.log),
  `preview-failed` (error on card and list), `uninit` (dev mode: no
  preview). Offscreen renders at 100 % and 50 % looked at.
- Hand mutants: engine 23 (22 killed; the `at` mutant survived first and
  got its test), plugin 15 (14 killed; three survived first: a failed
  source's note row got a test, the status trigger a harness case with a
  held probe). Survivors, both trigger wiring:
  - `deadline: Some(started + SCAN_BUDGET)` → `None` (the deadline itself is
    killed in `config_scan`'s tests; a wiring test needs a tree that takes
    more than 0.4 s to walk);
  - the refresh on the engine probe's answer (`onEngineStateChanged`): the
    harness waits for the probe before its first step, and the desk-open
    and status triggers cover every order it can reach; the trigger is for
    a desk opened while the probe still runs.
- Timing (release build, warm cache, synthetic home in the scratch dir):
  35 000 files under `~/.config` (a 20 000-file browser profile, a 5 000-file
  cache, 10 000 config files) and a 41 MiB `pacman.log`: `elapsedMs` 17,
  wall 19–20 ms over 5 runs. Cold cache not measured (needs dropping the
  page cache: sudo). The 0.4 s walk deadline bounds it anyway.
- `just check` (full, `SELDON_FULL_CHECK=1`, private `XDG_RUNTIME_DIR`,
  under the shared check lock) on `4bfda39f` (after the merge of
  `next`): **check: ok**, exit 0. The session's runtime dir stayed at 2 %.
