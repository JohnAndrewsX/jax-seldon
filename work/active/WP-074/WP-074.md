## Goal

- **F-542** — `Config.language` becomes an `Option`, so the locale
  default applies when the key is absent; the key either works after
  `init` or 06-configuration (en + de) stops promising that — choose,
  say why (init.rs ~515-518, config.rs ~235).
- **F-543** — a failure saving config.toml after the layout no longer
  leaves a logbook that `init` refuses: save the config before the layout
  or write the marker last (init.rs ~130-179, layout.rs ~74-81).
- **F-545** — `init --no-git` writes `[git] autocommit = false`
  (init.rs ~173-179, ~755-758); doctor no longer degraded for it.
- **F-546 / WP-052** — `init --theme-hook` takes the lock before the
  install and holds it through the own-write record and the commit; exit 4
  with nothing written while another `seldon` holds it (the WP-049
  pattern in hook.rs is the template).
