# WP-100 — Agent rules v2: templates, guide, skill text source, and the rules migration

Role: Docs + Engine Dev (Opus, high). First of the ADR-0027 set; WP-094
and WP-101 quote its text. No ADR beyond ADR-0027, no contract change.

## Goal

Every logbook — new or existing — carries the ADR-0027 rules: a case the
user started authorises the agent; act inside the Intent, plan as a
running note, preview line before the first privileged step; attended by
provenance; the agent snapshots itself (no cleanup pass) and records the
number; `alwaysRed` resolution check and the R3 stop; install-route
order; verify and close yourself; unattended means record and report.
Existing logbooks get the new rules with one command and keep the user's
own text.

## Inputs

ADR-0027 (final), ADR-0023 §2, ADR-0007, engine/templates/{en,de}/AGENTS.md,
docs/AGENT-GUIDE.md, docs/user/{en,de}/04-working-with-agents.md,
docs/user/{en,de}/05 (new commands), llms.txt, docs/SPEC-ENGINE.md §3
and §9 (init writes templates once, never overwrites), §5 rule 7 (own
writes), engine/src/commands/{init,doctor}.rs, engine/tests/golden/
init-skeleton.txt, the 2026-10-05 observation (private folder) as the
worked example's counter-example.

## Outputs

- `engine/templates/{en,de}/AGENTS.md` rewritten per ADR-0027 §2–§6 and
  §8; the engine-maintained part inside `<!-- seldon:begin rules v2 -->`
  … `<!-- seldon:end -->`; the `omarchy pkg add` rule becomes a
  recommendation; "propose and wait", "plan before you change anything",
  "`plan done` only when the user agrees" removed. Short, imperative,
  English keys and headings in both languages.
- `seldon rules update [--json]`: fenced file → rewrite the block only;
  unfenced file → insert the block at the top, keep the old text under
  `## Your rules (kept)`, print a diff; `--replace` archives the old file
  to `archive/AGENTS-<date>.md` and writes the template; autocommit
  `seldon: rules update`; idempotent (second run: no change, exit 0);
  exit 3 without a logbook.
- `seldon doctor` row `rules: current | outdated (v1) | missing — fix:
  seldon rules update`; the fix in `doctor --json` so the panel's doctor
  banner can offer it (plugin change is one row, in this WP).
- docs/AGENT-GUIDE.md §3, §4, §8, §9 (worked example: the 2026-10-05
  task done right — one sentence, one prompt, agent closes), §10;
  guide 04 en/de; guide 05 en/de (`rules update`); llms.txt; SPEC-ENGINE
  §3 and §9; SPEC-LOGBOOK §3 "who closes"; CHANGELOG.
