# WP-001 — Repo scaffold, CI, toolchain

## Goal
A repository where every later WP can run its acceptance tests with one
command.

## Inputs
AGENTS.md §4 §7, docs/SPEC-ENGINE.md §1, docs/SPEC-PLUGIN.md §9.

## Outputs
- `engine/Cargo.toml` (crate `seldon`, edition 2024, bin `seldon`), `src/main.rs` with `--version` and `contract-version`.
- `plugin/manifest.json` (from SPEC-PLUGIN §1, verified against the installed shell README), empty `Service.qml`, `BarWidget.qml`, `Overlay.qml` that load.
- `justfile`: `check` (fmt, clippy -D warnings, test, schema validate, plugin validate, qmllint), `build-release` (musl), `fixtures-refresh`.
- `.github/workflows/ci.yml` running `just check` on Arch container with omarchy tooling where possible; document what cannot run in CI.
- `.gitignore`, `LICENSE` (MIT), `CHANGELOG.md` (keep-a-changelog).

## Acceptance tests
- `just check` exits 0 on a clean clone (on the dev host).
- `seldon --version` prints `seldon 0.1.0`; `seldon contract-version` prints `1`.
- `omarchy plugin validate plugin/` exits 0.

## Constraints
No functionality beyond stubs. Note every shell README finding in `memory/omarchy-shell.md`.
