# WP-067 — plugin: tab change returns keyboard focus; changelog cursor follows its event; IPC handler once

Role: Plugin Dev (Opus, high). Size: S. Wave: 3. Depends: WP-060
(`tests/plugin/panel-view.sh`). Findings: F-552, F-554, F-253 (Info,
verify first).

## Goal

- **F-552** — `selectTab()` (Panel.qml ~83-86) returns focus to the key
  catcher; Today and Work tabs drop focus when hidden (`onVisibleChanged`),
  so Enter never submits from an invisible field (WorkTab.qml ~187 only
  disarms today).
- **F-554** — the Changelog cursor (ChangelogTab.qml ~38, ~120) keeps the
  event id under the cursor and re-finds its row on `rowsChanged`, as
  WorkTab does with `selectedId` (~49).
- **F-253** — reproduce the duplicate `IpcHandler` warning
  (BarWidget.qml ~140, target `jax.seldon.panel`) in the harness with two
  bar instances. Reproduced → register once (check how the built-in
  plugins in `$OMARCHY_PATH/shell/plugins/` do it). Not reproduced → no
  code change; the handover records the attempt and the finding is closed
  as not reproduced.
