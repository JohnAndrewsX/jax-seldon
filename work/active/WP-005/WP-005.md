# WP-005 — Collectors: plugins, theme, config manifest

## Goal
Diff-based collectors for the user-space state Omarchy manages: shell
plugins, the active theme, and watched config files.

## Inputs
docs/SPEC-ENGINE.md §4 §7, schema/event.schema.json,
fixtures/logs/plugin-list-{before,after}.json, memory/host.md (theme file
path, `omarchy plugin catalog` for versions).

## Outputs
- `engine/src/collectors/plugins.rs` — snapshot of `omarchy plugin list --json` + `omarchy plugin catalog` (for versions), stored by hash; diff → `plugin-add|plugin-remove|plugin-enable|plugin-disable|plugin-update`.
- `engine/src/collectors/theme.rs` — reads `~/.local/state/omarchy/current/theme.name`; diff → `theme-set`. Ships the optional `theme-set.d` hook script (`seldon event theme theme-set --subject "$1"`) under `engine/hooks/`; installed by the wizard via `omarchy hook install theme-set <file>` only when the user opts in.
- `engine/src/collectors/config.rs` — sha256 manifest in `~/.local/state/seldon/manifest.json` over `watchPaths` (defaults per SPEC-ENGINE §4; `~/.config/omarchy` excluding `plugins/`); `config-add|config-change|config-remove` with path and both hashes; binary files and files > 1 MB skipped; `[redaction] skipPaths` never hashed.

## Acceptance tests
- Diff-based events are correct on the fixtures (before/after pairs for each collector).
- `skipPaths` honoured (a fixture secret file never appears in the manifest).
- Files > 1 MB skipped (test creates one in a temp dir).
- Second run yields 0 events.
- Events validate against the schema.

## Constraints
Read-only on the host. Paths in events are written with `~` for the home
directory (SPEC-LOGBOOK §7: no absolute private paths).
