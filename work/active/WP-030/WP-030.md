# WP-030 — Overlay skeleton, grid, period selector, keyboard

## Goal
The Prime Radiant overlay opens, lays out a grid of chart slots that hold
at 1920×1080 and 2560×1440, offers a period selector, and closes on Esc.
WP-031 fills the slots.

## Inputs
docs/SPEC-PLUGIN.md §6 (Overlay — Prime Radiant), §7 §8 §9, docs/CONTRACT.md,
schema/index.schema.json (`series.*`, `summary`, `drift`, `cases`),
fixtures/index.sample.json (series: heatmap 366 days, packages, drift
weeks, risk, timeline), plugin/Overlay.qml (WP-001 stub: `PanelWindow`,
`open(payloadJson)`/`close()`/`opened`, Esc), plugin/Service.qml,
memory/omarchy-shell.md (routing: `shell toggle jax.seldon` → the overlay;
`service` injected; `Color.menu.scrim`), built-in overlays under
`$OMARCHY_PATH/shell/plugins/` for layout patterns, work/completed/WP-{010,011,021}/HANDOVER.md.

## Outputs
- `plugin/Overlay.qml`: fullscreen `PanelWindow` with scrim, header
  (title, logbook machine, generatedAt, period selector), a responsive
  grid of five slots (Heatmap, Series, DriftBars, RiskDonut, Timeline)
  with placeholders that show the slot name and the row count of the
  series they will render; footer with the keys.
- Period selector: 30 d / 90 d / 365 d / all (keys `1`–`4`, `←/→`), a
  `period` property the charts (WP-031) bind to; the slots show the
  selected window's counts from the fixture series.
- Opens via `shell toggle jax.seldon` / `summon` (IPC) and the pill's
  middle click (WP-010 wiring); closes on Esc and on a click on the scrim;
  `opened` reflects the state; the overlay never blocks the shell thread
  and reads only the service's `index`.
- Layout holds at 1920×1080 and 2560×1440 (and a 1.25 scale): assert in
  an offscreen harness with both window sizes (`tests/plugin/overlay-view.sh`
  with a stand-in for `PanelWindow` as the panel harness did for
  `KeyboardPanel`); `view` IPC for the overlay (`jax.seldon.overlay`?
  — follow SPEC §8: the overlay entry point; add a read-out method if the
  spec allows, else expose state via the service snapshot).
- `plugin/Model.js`: `periodWindow`, `seriesInPeriod` helpers; node tests.
- README/TESTING; offscreen renders at both sizes in three themes under
  work/active/WP-030/screenshots/.

## Acceptance tests
- `just check` exit 0 (qmllint zero warnings, tokens, harnesses).
- Opens via IPC and closes on Esc in the harness; `opened` toggles;
  placeholders show the right counts for each period on the sample.
- Layout at 1920×1080 and 2560×1440 without overflow (harness asserts
  slot geometry inside the window, no clipping warnings in the log).
- Runtime smoke on the test host over IPC (`shell toggle jax.seldon`,
  `hide`) — keys/screenshots only if unlocked (ORCHESTRATION.md §11).

## Constraints
As the panel WPs: tokens only, no synchronous work on open (no frame
drops: keep the first frame cheap, defer heavy aggregation), fixed
argument lists (the overlay runs no engine commands in this WP), dev host
copy-only, a guard block is reported, never worked around.
