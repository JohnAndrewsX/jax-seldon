# Security policy

This plugin (`jax.seldon`) is developed in
[JohnAndrewsX/jax-seldon](https://github.com/JohnAndrewsX/jax-seldon),
under `plugin/`; this repository is generated from it. The security
policy there covers the plugin too:
[SECURITY.md](https://github.com/JohnAndrewsX/jax-seldon/blob/main/SECURITY.md).

**Do not open a public issue for a vulnerability.** Report it privately:

- [Report a vulnerability](https://github.com/JohnAndrewsX/jax-seldon/security/advisories/new)
  in the main repository (preferred), or in this repository's
  *Security* tab;
- or e-mail the maintainer at `e.andres+aur@ik.me`.

The plugin runs unsandboxed inside the Omarchy shell process; what it
reads and runs is listed under "Security, privacy, privileges" in
[README.md](README.md).
